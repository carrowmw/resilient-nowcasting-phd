# Architecture Decision Records (ADRs)

This directory records significant architecture decisions for the NSTAR backend — the context, the
decision taken, and its consequences — so the *why* behind the code survives.

Each ADR is immutable once **Accepted**; revisit by adding a new ADR that supersedes it rather than
editing history.
