# ML Agent Workspace

## Build Instructions

To build the agent workspace container on your local machine, run the following command in the terminal:

```Bash
docker compose build agent-workspace
```

This will build the container that you will use for development on your Mac.

```Bash
docker compose build cpu-runner
```

When you are ready to execute your training script on the GPU server, you will need to build the CUDA image. Run the following command on the server:

```Bash
docker compose build gpu-runner
```

## Execution Instructions

### On Mac (Development):

You will boot the interactive terminal exactly as you have been doing to let the agent code:

```Bash
docker compose run --rm agent-workspace bash
```

### On the GPU Server (Execution):

Once you have pushed your main branch to GitHub and pulled it down to the server, you will run the GPU container to execute the W&B training script:

```Bash
docker compose run --rm gpu-runner python src/process_all.py
```

```Bash
# This builds the CUDA image and runs your training script
docker compose run --rm gpu-runner python src/train.py --epochs 50 --batch_size 128
```

```Bash
# This maps the GPU, mounts the repo, and runs exactly one month of data
docker compose run --rm gpu-runner python src/train.py \
  --epochs 2 \
  --batch_size 128 \
  --start_date "2023-03-02" \
  --end_date "2023-04-02"
```

## Hyperparameter Tuning (Optuna)

The tuning entry point is `src/tune.py`. It launches an Optuna study and logs trial metrics to Weights & Biases through `WeightsAndBiasesCallback`.

The search space is defined in `configs/sweep.yaml`:

- `lr` (log-uniform)
- `w_forecast` (uniform)
- `w_impute` (uniform)

### Local CPU Smoke Sweep (Mock Data)

Use this first to validate the full tuning loop quickly on your Mac:

```Bash
docker compose run --rm cpu-runner python src/tune.py --use_mock_data
```

If you want to keep runs local-only and avoid syncing to W&B cloud:

```Bash
docker compose run --rm cpu-runner bash -lc 'WANDB_MODE=offline python src/tune.py --use_mock_data'
```

### GPU Server Sweep (Real Data)

Run this on the GPU server after pulling the latest code and setting your `.env`:

```Bash
docker compose run --rm gpu-runner python src/tune.py
```

Recommended explicit run (select your exact data window and stream):

```Bash
docker compose run --rm gpu-runner python src/tune.py \
  --n_trials 2 \
  --epochs 2 \
  --batch_size 4 \
  --start_date 2023-10-01 \
  --end_date 2023-10-04 \
  --veh_class person \
  --dir all
```

### Logs and Outputs

- Sweep logs are written to `logs/optuna_sweep_YYYYMMDD_HHMMSS.log`
- Best parameters and best validation loss are printed at the end of the run

### Tune CLI Options

`src/tune.py` now supports CLI overrides so you do not need to edit source code for most sweep changes:

- `--n_trials`
- `--epochs`
- `--batch_size`
- `--start_date`
- `--end_date`
- `--seq_len`
- `--veh_class`
- `--dir`
- `--use_mock_data`

Show all options:

```Bash
docker compose run --rm cpu-runner python src/tune.py --help
```

### Troubleshooting: Empty Data Window / Filter Errors

If your selected `--start_date`, `--end_date`, `--veh_class`, or `--dir` produces no rows, tuning will fail fast with a clear error explaining which filter removed all rows and which values were available in the loaded data. Adjust the date window or stream arguments and rerun.

# SYSTEM ROLE: SENIOR MACHINE LEARNING ENGINEER

You are an autonomous Machine Learning Agent operating within a containerized Linux environment. You have read/write access to the local filesystem. Your objective is to build, test, and debug machine learning pipelines securely and reproducibly.

## 1. RULES OF ENGAGEMENT

- **Plan First:** Do not write execution code immediately upon receiving a complex request. First, output a step-by-step architectural plan to a file named `plan.md`. Wait for the user's explicit approval before writing the Python scripts.
- **Safety First (Git):** Before making any multi-file changes or refactoring working code, you MUST execute `git add .` and `git commit -m "Auto-commit before [Task Name]"` to ensure the user has a rollback point.
- **Autonomy:** You have permission to run standard bash commands (e.g., `ls`, `cat`, `python`, `pip install`) to explore the environment and test your code. Do not ask for permission to run read-only or testing commands. Do ask for permission before deleting entire directories or dropping databases.

## 2. MACHINE LEARNING STANDARDS

- **Reproducibility:** Every script must include standard random seed initialization for numpy, pandas, scikit-learn, and torch/tensorflow at the very top of the execution block.
- **Defensive Data Handling:** Before passing data into a model, you must explicitly print/log the tensor or dataframe shapes (e.g., `X.shape`, `y.shape`). If there is a mismatch, catch it and fix the reshaping logic before proceeding.
- **Directory Structure:** Adhere strictly to the workspace structure.
  - Raw data is in `./data/`. Treat this as READ-ONLY.
  - Python scripts go in `./src/`.
  - Trained model artifacts (`.pkl`, `.pt`, `.h5`) must be saved to `./models/`.

## 3. CODE QUALITY

- Write modular, functional Python (3.11+). Avoid massive, monolithic scripts.
- Use Python type hints (`def process_data(df: pd.DataFrame) -> np.ndarray:`) for all function definitions.
- Include concise docstrings explaining the input/output of complex data transformations.
- Favor logging (`import logging`) over standard `print()` statements for tracking training epochs and data pipeline progress.

## 4. ERROR RESOLUTION

- If a Python script throws an error during your testing, do not immediately ask the user for help.
- Read the traceback, identify the exact line of failure (often a tensor dimension mismatch, a missing column, or a NaN value), apply a fix, and rerun the script.
- Only present the final, working output to the user, summarizing the errors you encountered and how you resolved them.
- Store tests and debugging scripts in a separate `./tests/` directory. Do not clutter the main `./src/` directory with temporary code.

## 5. OFFENSIVE PROGRAMMING PARADIGM (FAIL FAST / FAIL HARD)

- You are writing prototype ML code. Do NOT write defensive code that silently handles errors, coerces data types, or suppresses exceptions.
- **Assert Everything:** Use `assert` statements aggressively at the top of functions to validate matrix shapes, exact data types, and expected column names.
- **Let it Burn:** Never use a bare `except:` block. If an unexpected error occurs, the script must crash immediately and print the full traceback so the error can be diagnosed.
- **Tripwires:** If a tensor operation or pandas transformation might introduce NaNs or infinites, add an explicit check immediately after the operation to crash the script if they are detected.
- **No Silent Drops:** Do not use `.dropna()` or `.fillna()` silently unless explicitly instructed as part of the data cleaning plan.

## 6. THE EXPERIMENT LEDGER (DOCUMENTATION MANDATE)

- You are required to maintain a strict log of all major architectural changes and model training runs in `EXPERIMENTS.md`.
- **Branching Protocol:** Whenever you are instructed to build a new model or start a major feature, you must first ask the user if they have created a new Git branch.
- **Logging Protocol:** Upon completing a training run, building a new pipeline component, or hitting a dead end, you MUST append a new row to the table in `EXPERIMENTS.md`.
- The row must include the current date, the active Git branch name, a summary of the exact prompt/goal that initiated the work, and the mathematical or functional outcome.
- A task is only considered 'Done' once the outcome has been recorded in EXPERIMENTS.md.
- You are strictly forbidden from saying "The task is complete" or "I have finished" in your response unless you have already updated the ledger in the same turn.

## 7. THE NORTH STARS (NSTAR_BACKEND_ARCHITECTURE.md, NSTAR_FRONTEND_ARCHITECTURE, NSTAR_MLOPS.md, & NSTAR_PHASES.md)

- The Blueprints: You have three global design documents.
  1. Use `NSTAR_BACKEND_ARCHITECTURE.md` for any PyTorch module, tensor, or mathematical logic.
  2. Use `NSTAR_FRONTEND_ARCHITECTURE.md` for any Next.js, Deck.gl, or geospatial UI logic.
  3. Use `NSTAR_MLOPS.md` for any task involving training loops, Weights & Biases, Optuna, or Docker execution.
  4. Use `NSTAR_PHASES.md` as your temporal anchor. You must strictly adhere to the constraints of the current Phase (e.g., do not write live API fetching logic if the project is currently in the Static Payload phase).
- Piecewise Execution: DO NOT attempt to build the entire system at once. You must only build the specific component requested in the user's prompt.
- Strict Adherence: The constraints listed in NSTAR_BACKEND_ARCHITECTURE.md (especially regarding loss functions, tripwires, and data masking) are absolute. Do not substitute them with standard generic functions.

## 8. THE DESK CHECK MANDATE

When asked to review mathematical logic, metrics, or loss functions, you are forbidden from simply saying "the logic looks correct." You MUST run a simulated "Desk Check." You must create a dummy scenario with extreme, unbalanced numbers (e.g., a batch of 100 vs a batch of 1, or an input tensor of exactly 0.0), trace the exact mathematical execution of the code, and prove that the final output matches the theoretical target.

You are strictly forbidden from reading, listing (ls), or attempting to parse the contents of the following directories and file types: `wandb/`, `logs/`, `models/`, `.next/`, `.pytest_cache/`, `**pycache**/`, `_.parquet`, and `_.pt`.

Do not pipe raw data into this chat.

No Local Installs: You must NEVER run npm install or pip install directly on the host machine. All dependencies must be installed inside their respective Docker containers.

Node Modules Quarantine: Frontend dependencies are managed via Docker anonymous volumes. If you need to install a new frontend package (e.g., `npm install d3`), you must execute it inside the running frontend container using `docker compose exec [service_name] npm install d3`.

services:

  agent-workspace:
    build:
      context: .
      dockerfile: Dockerfile.agent
    container_name: my-ml-agent
    volumes:
      - .:/workspace
    # Port mapping to allow the browser to access the app inside the container.
    ports:
      - "3000:3000"
    # Notice we don't even need the 'environment:' block anymore!
    # Compose passes the .env file automatically.
    stdin_open: true
    tty: true

  # Run on GPU server for training.
  gpu-runner:
    build:
      context: .
      dockerfile: Dockerfile.gpu
    container_name: gpu-executor
    volumes:
      - .:/workspace
    # We explicitly pass the WANDB_API_KEY from the server's .env file
    environment:
      - WANDB_API_KEY=${WANDB_API_KEY}
    # This block maps the physical server GPUs into the container
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              device_ids: ["0", "1"]
              capabilities: [gpu]

  # Run on local CPU server for testing.
  cpu-runner:
    build:
      context: .
      dockerfile: Dockerfile.cpu
    container_name: cpu-executor
    volumes:
      - .:/workspace
    # We explicitly pass the WANDB_API_KEY from the server's .env file

      - WANDB_API_KEY=${WANDB_API_KEY}

# Exploratory Data Analysis (EDA) Summary

## 1. Datasets Overview

### Traffic Data (`traffic_20230108_20260108.parquet`)
- **Size:** 21,144,475 records, 6 columns.
- **Columns:** `category` (str), `dir` (str), `dt` (datetime64), `location` (str), `value` (int64), `veh_class` (str).
- **Date Range:** 2023-03-02 to 2026-01-08.
- **Description:** Contains traffic measurements (e.g., flow) at various sensor locations broken down by vehicle class (e.g., 'person', 'car') and direction.

### Weather Data (`weather_20230108_20260108.parquet`)
- **Size:** 2,715,140 records, 13 columns.
- **Columns:** `sensor_name` (str), `variable` (str - e.g., 'Humidity', 'Solar Radiation'), `timestamp` (datetime64), `value` (float64), `units` (object), `flagged` (bool), `location_wkt` (str), `sensor_centroid_latitude` (float64), `sensor_centroid_longitude` (float64), `sensor_height_above_ground` (float64), `ground_height_above_sea_level` (float64), `broker_name` (str), `raw_id` (str).
- **Date Range:** 2023-01-08 to 2025-10-20.

### Sensor Metadata JSONs
- **`traffic_sensors.json`:** Maps string `location` identifiers to numeric `lat` and `lon` coordinates.
- **`weather_sensors.json`:** Maps `Sensor_Name` identifiers to `Location_WKT`, `Sensor_Centroid_Latitude`, `Sensor_Centroid_Longitude`, and elevation details.

---

## 2. Likely Target Variable
The likely target variable for predictive modeling is **`value`** in the **Traffic dataset**. 
Since `Congestion_Level` is not present, `value` corresponds to the quantitative traffic flow/volume or speed metric at a given location and time. The goal of an ML pipeline here would likely be to predict the future traffic `value` using historical traffic patterns and correlated weather phenomena.

---

## 3. Data Quality Summary

### Missing Values
- **Traffic Data:** While the data dictionary may suggest a clean dataset with **0 missing values**, this is because missing data in this table does not appear as explicit `NaN` values. Instead, the time series is **irregular and contains missing timestamps (gaps)**.
    - **Temporal Gaps:** The standard measurement frequency should be **15 minutes**. However, the time series is highly irregular: **~23% of gaps** between consecutive sensor readings are larger than 15 minutes, meaning countless timestamps have simply been dropped from the dataset rather than being recorded as null.
    - **Zero-Count Deletion:** Only 1,964 records (out of 21.1M) have a `value` of 0. This confirms that missing periods and zero-traffic moments were omitted. This irregular structure must be corrected via temporal resampling/re-indexing before sequential modeling.
- **Weather Data:** The **`units`** column is entirely empty (2,715,140 missing values) and should be dropped. All other 12 columns contain **0 missing values**.

### Outliers and Anomalies
- **Negative Traffic Values:** The `value` column in the traffic dataset has a minimum value of **-27**. Assuming this represents a physical count of vehicles or traffic flow, negative numbers are physically impossible and represent anomalous readings, sensor errors, or special null-equivalent codes (e.g., similar to a -99 placeholder). These must be filtered or imputed before training.
- **Traffic Maximums:** The maximum `value` is 2,691, with a mean of 13.3 and a 75th percentile of 10. The large max value may represent sudden heavy bursts of traffic or aggregated anomalies.

### Class Imbalances / Distributions
- **Traffic `category`:** Heavily imbalanced towards `'flow'` (20.5M out of 21.1M records). 
- **Traffic `veh_class`:** The most frequent class is `'person'` (6.8M records), though there are 16 unique vehicle classes overall.
- **Traffic `dir` (Direction):** 'east_to_west' is the most heavily represented direction (4.1M records) out of 122 unique directions.
- **Weather `variable`:** Dominated by `'Humidity'` (1.38M out of 2.7M records) and collected predominantly by the `aq_mesh_api` broker.

## 4. Next Steps for Pipeline Design
1. **Data Cleaning:** Drop `units` from weather data. Filter or handle negative `value` anomalies in the traffic dataset.
2. **Temporal Alignment:** Re-index the traffic dataset to a continuous 15-minute time series (resampling and filling gaps with zeros or imputed values) to restore physical continuity.
3. **Data Integration:** Use spatial coordinates (from the JSON files) to map traffic sensors to the nearest weather sensors, subsequently merging the dataframes on datetime (`dt` and `timestamp`) and location identifiers.
4. **Feature Engineering:** Extract temporal features (hour, day of week, month) from the datetimes, pivot weather variables to columns, and aggregate traffic volumes to a consistent time-frequency (e.g., hourly).

# NSTAR_BACKEND_ARCHITECTURE.md

## Objective

Implement an end-to-end, joint spatiotemporal graph neural network in PyTorch and PyTorch Geometric (PyG). The model is designed for an urban IoT sensor network predicting a configurable target traffic stream (defined by vehicle class and spatial direction) every 15 minutes. It must be self-healing, capable of dynamic graph inference, missing feature imputation, and uncertainty-aware forecasting. **The pipeline must remain strictly univariate per run** to prevent gradient interference across different vehicle classes.

## Core Paradigm

The system abandons the I.I.D. assumption, leveraging Graph Attention Networks (GATs) to pass messages along dynamically learned topological connections, alongside Transformers for temporal sequence modelling.

### 1. Architectural Components

The pipeline (`ResilientIoTPipeline`) consists of three primary modules sharing a latent space:

#### Dynamic Graph Learner (Topology Inference):

- Takes static node features (e.g., coordinates, sensor types).
- Uses a multi-head GAT (or linear embeddings with pairwise similarity) to learn a dynamic adjacency matrix on the fly.
- Applies a ReLU and a sparsity threshold, converting the dense matrix to PyG's `edge_index` and `edge_weight` using `dense_to_sparse`.

#### Masked Spatiotemporal Encoder (Feature Extraction):

- Takes artificially masked dynamic time-series data and the inferred graph structure.
- **Spatial:** Uses PyG `GATv2Conv` layers to aggregate neighbourhood features.
- **Temporal:** Flattens the spatial output and passes it through a standard PyTorch `TransformerEncoder`.

#### Decoupled Decoders (Multi-Task Learning):

- **Imputation Decoder:** An MLP (e.g., Linear -> GELU -> Dropout -> Linear) applied across the entire sequence to reconstruct the masked historical data.
- **Uncertainty-Aware Forecasting Decoder:** An MLP taking the final time step's embedding. Outputs three parameters representing a Zero-Inflated Negative Binomial (ZINB) distribution: $\mu$ (mean), $\theta$ (dispersion), and $\pi$ (zero-inflation probability).

### 2. Data Pipeline Specifications

The PyTorch Dataset must yield a dictionary for each batch. Target variables must strictly remain as raw, unscaled counts, while input dynamic/static features must be normalized via `StandardScaler` to prevent gradient starvation.

### 3. Joint Training & Loss Logic

The model must be trained simultaneously on all tasks. Total Loss = $(w_{forecast} \times \mathcal{L}_{ZINB\_NLL}) + (w_{impute} \times \mathcal{L}_{impute\_MSE})$.

- **ZINB Tripwires:** Apply `F.softplus` to $\mu$ and $\theta$ raw logits, plus an `eps=1e-6` buffer to mathematically guarantee they never equal zero.

### 4. Model Development & Ablation Strategy

Before reaching final production architecture, the pipeline must undergo structured evaluation:

- **Baseline Benchmarking:** Before tuning GNN hyperparameters, visualize a "Last Observation Carried Forward" (LOCF) or Historical Average model. The deep learning pipeline must visually and mathematically outperform these dumb baselines.
- **Zero-Inflation ($\pi$) Tuning:** Do not rely on a hardcoded `0.5` threshold to determine structural zeros. Plot the ROC curve for the $\pi$ parameter to find the optimal threshold for traffic shut-offs (e.g., nighttime periods).
- **Component Ablation:** Systematically disable the `DynamicGraphLearner` and swap the `GATv2Conv` for temporal-only baselines to isolate the exact performance delta generated by the graph topology.

# NSTAR_FRONTEND_ARCHITECTURE.md

## Objective

Implement a Geospatial Digital Twin for the Resilient IoT network. ### A. The Node Layer (Predictions & Uncertainty)

- **Component**: Deck.gl ScatterplotLayer.
- **Data Source**: Sensor locations (real) and Simulated Nodes.
- **Visual Mapping**:
  - **Fill Color (Uncertainty)**: Mapped to the 95% Confidence Interval derived from the ZINB $\theta$ (dispersion) parameter.
  - **Stroke/Halo Radius (Prediction)**: Mapped to the ZINB $\mu$ parameter (mean predicted traffic). A wider radius indicates higher predicted values. Uses a logarithmic scale to accommodate the wide range of traffic volumes.
  - **Simulated Nodes**: Visually distinct (e.g., using a dashed stroke or distinct shape) to indicate the prediction is a zero-shot topological inference, not a physical sensor.

### B. The Topology Layer (Attention Weights)

- **Component**: Deck.gl `ArcLayer` or `LineLayer`.
- **Data Source**: The attention_sequence extracted from the GATv2Conv layers.
- **Visual Mapping:** Opacity/Width mapped to the attention weight ($\alpha$). Must be aggressively filtered to top _N_ edges to prevent visual clutter.

### C. The Road-Constrained Heatmap (Spatial Interpolation)

- **Component:** Deck.gl `PathLayer` rendering GeoJSON LineStrings.
- **Mechanism:** PostGIS functions (`ST_ClosestPoint`, `ST_Distance`) interpolate the ZINB $\mu$ values between adjacent sensors to color-code continuous road segments representing traffic flow.

- **The Global Clock:** A single integer state (`currentTimestep`) managed by `useTimeStore`.
- **Interpolation Logic:** Deck.gl layers must linearly interpolate positions, colors, and radii between `timestep[t]` and `timestep[t+1]` for smooth animation.
- **Data Slicing:** The React components do not filter the massive data payload. Deck.gl layers receive the full data arrays and use **DataFilterExtension** (a WebGL shader extension) to efficiently hide/show data on the GPU based on `currentTimestep`.

### Phase 1: The Static Prototype (Memory-Bound)

### 1c. Inverse-transform imputed values into raw-count space (DESK CHECK MANDATE)

`StandardScaler` was fit at dataset init on flattened dynamic features of shape
`(num_times * num_nodes, 3)` — channel order is `[value, Humidity, Solar Radiation]`.
The scaler stores `mean_[3]` and `scale_[3]` (one per feature).

`StandardScaler.transform(x) = (x - mean_) / scale_`
`StandardScaler.inverse_transform(z) = z * scale_ + mean_`

**Desk Check (extreme cases):**

| Scenario | Input (raw count) | Expected scaled | Expected inverse |
| :--- | :--- | :--- | :--- |
| Mean ≈ 50, scale ≈ 25 | x = 100 | (100−50)/25 = **2.0** | 2.0·25 + 50 = **100** ✓ |
| Mean ≈ 50, scale ≈ 25 | x = 0 | (0−50)/25 = **−2.0** | −2.0·25 + 50 = **0** ✓ |
| Mean ≈ 50, scale ≈ 25 | x = 1 (extreme low batch) | (1−50)/25 = **−1.96** | −1.96·25 + 50 = **1** ✓ |
| Pathological scale ≈ 0 | — | divide-by-zero (sklearn auto-bumps to 1.0) | safe |

We extract channel 0 (traffic count) only:
`unscaled = scaled * scaler.scale_[0] + scaler.mean_[0]`

We must **NOT** apply softplus / clamping to the imputed traffic — the imputation
decoder targets `target_impute` which is the *scaled* dynamic features (per
`dataset.py` line 154: `target_impute = dyn_tensor.clone()` after scaling).
After inverse-transform, residual negative reconstructions are honest model
artifacts and must be displayed as-is. (We may `clamp(min=0)` for the *displayed*
ground truth series to match the dataset's `clamp(min=0)` on raw counts.)

**Tripwire:** assert `not torch.isnan(imputed_features).any()` before saving.
Assert `scaler.scale_[0] > 0` before inverse-transform.

### 1d. Per-timestep extraction strategy (96 windows → length-96 arrays)

For each window `idx ∈ [skip, skip + 96)` and each node `n`:
- `imputed_at_t = inverse(imputed_features[0, n, -1, 0])` — last step of the

- `ground_truth_at_t = unscaled_traffic[idx + seq_len - 1, n]` — pulled directly
  from `dataset.unscaled_traffic` (already in raw-count space; no inverse needed).
  For **simulated nodes**, `ground_truth_at_t = null` (no physical sensor).
- `mask_at_t = node_mask[n, -1, 0]` for real nodes; for simulated nodes,
  `mask_at_t = True` (every input was NaN → fully imputed by definition).

Result: each node carries three arrays of length 96.

## Step 3 — `frontend/src/components/MapVisualizer.tsx`

### 3a. Hollow-ring vs solid-disc for ScatterplotLayer
Per FRONTEND_ARCHITECTURE.md §A: simulated nodes must be visually distinct.
A single `ScatterplotLayer` accepts only one stroked/filled mode globally (the
flags are layer-wide, not per-row), so we **split into two layers**:
  - `nodes-real` — `data: payload.nodes.filter(n => !n.is_simulated)`,
    `stroked: false, filled: true`.
  - `nodes-simulated` — `data: payload.nodes.filter(n => n.is_simulated)`,
    `stroked: true, filled: false, lineWidthMinPixels: 3,
    getLineColor: getFillColor` (so the ring inherits the uncertainty heat).
Both layers share accessors and `updateTriggers: [timestep]`.

### 3b. Click-to-select node
Add `onClick: ({ object }) => setSelectedNodeId(object?.id ?? null)` on both
node layers, plus a click on empty map deselects (`map.on('click', ...)` falling
through when no Deck.gl object is hit — using `pickable: true`).

### 3c. ArcLayer: ego-graph isolation + threshold filtering
Replace top-N filter with two new filters applied in sequence:

```ts
const { selectedNodeId, attentionThreshold } = useTimeStore(...);
const filtered = payload.edges
  .map(e => ({ edge: e, weight: e.attention_sequence[timestep] ?? 0 }))
  .filter(x => x.weight >= attentionThreshold)
  .filter(x =>
    selectedNodeId == null ||
    x.edge.source === selectedNodeId ||
    x.edge.target === selectedNodeId
  );
```
- `attentionThreshold` from Zustand drops low-weight noise.
- If `selectedNodeId` is set, restrict to ego-graph edges (source OR target ==
  selected).
- Keep an upper cap (e.g. `slice(0, 60)`) as defensive bound when
  `selectedNodeId == null`, to preserve the existing "no hairball" property.
- Add `selectedNodeId, attentionThreshold` to the `useEffect` dependency array
  so layers rebuild when filters change.
- Add both to layer `updateTriggers` for full Deck.gl correctness.

### 3d. Defensive rendering (FRONTEND_ARCHITECTURE.md §2)
If `node.imputed_series` is `undefined` (older payload), gracefully skip the new

# Agentic Workflow Summary

## Phase 1: Infrastructure & Security

The foundation of this workflow is an isolated, disposable environment where your code is safe, but the agent's memory is intentionally volatile.

- The Unified Dockerfile: Your image is built on a lightweight Python base. It installs system dependencies, Node.js (for Gemini CLI), and native curl binaries (for Claude Code), alongside your Python ML requirements.

- Volume Mounts (The Portal): You map your local Mac directory to /workspace inside the container. This ensures your code, data, and models are permanently saved on your host machine, while the agent edits them live from inside the container.

- Security (.env & .gitignore): API keys are never baked into the Docker image or stored globally in ~/.zshrc. They are strictly kept in a local .env file, which is added to .gitignore to prevent accidental GitHub leaks.

- The --rm Mandate: You boot the environment using docker compose run --rm agent-workspace bash. The --rm flag is critical: it ensures that the moment you exit the shell, the container and the agent's internal chat history are completely destroyed, giving you a pristine state for your next session.

## Phase 2: The Agent's Operating System (System Prompt)

The agent is governed by a strict system prompt (saved as GEMINI.md or CLAUDE.md in your workspace) that establishes its rules of engagement.

- Plan First: The agent is forbidden from writing complex execution code immediately. It must first write a step-by-step architectural plan to plan.md and wait for human approval.

- Safety First (Git): The agent must execute git commit to create local rollback points before refactoring working code or beginning new major tasks.

- The Experiment Ledger: The agent is mandated to maintain an EXPERIMENTS.md file, logging the date, active branch, prompt used, and the mathematical outcome of every model training run.

## Phase 3: The "Offensive ML" Coding Paradigm

Machine learning prototyping requires "Offensive Programming." The agent is instructed to write code that fails fast and hard rather than silently coercing bad data.

- Ruthless Assertions: The agent must explicitly assert tensor shapes, dataframe columns, and exact data types at the top of every major function.

- Let it Burn: Generic except: blocks are banned. If a matrix dimension mismatches, the script must crash immediately and print the full traceback for diagnosis.

- NaN Tripwires: The agent must place explicit checks after transformations to crash the script if unexpected NaNs or infinite values are introduced.

- No Silent Drops: Functions like .dropna() are banned unless explicitly approved in the data cleaning plan.

## Phase 4: The Execution Loop (Human-in-the-Loop Orchestration)

You act as the Senior Engineer; the AI acts as the Junior Developer. You do not ask the agent to "build a pipeline." You micro-batch its tasks.

- The Blind EDA: You begin by asking the agent to analyze the raw data without telling it what the data is or what your goal is. This forces the agent to read the literal matrix (identifying true anomalies like time-series gaps) rather than hallucinating a perfect dataset.

- The Common Preprocessing Pipeline: Based on the EDA, the agent builds a single, hardened data pipeline (handling resampling, imputation, and spatial joins) that outputs clean matrices (e.g., .npy files). This is committed to the main Git branch.

- The Crash-and-Fix Loop: When the agent writes a script, you run it. When it crashes (due to your offensive programming assertions), you do not fix it yourself. You paste the exact traceback back to the agent and instruct it to resolve the anomaly.

## Phase 5: State Management (Git Branching & Memory Wipes)

To prevent the agent's context window from degrading into a polluted mess of broken PyTorch tensors and overlapping logic, you strictly sandbox your experiments.

- Model Sandboxing: Every new model architecture (e.g., XGBoost, Random Forest, Neural Networks) gets its own Git branch branched off main.

- The Context Wipe: Before starting a new branch or moving to a radically new step in the pipeline, you explicitly clear the agent's memory (using /clear or restarting the CLI).

- Re-Grounding: Upon starting a fresh branch or cleared session, you point the agent to the current working state of the files and the EXPERIMENTS.md ledger, ensuring it builds exclusively on clean, working logic.

"use client";

import { useEffect, useRef } from "react";
import maplibregl from "maplibre-gl";
import "maplibre-gl/dist/maplibre-gl.css";
import { MapboxOverlay } from "@deck.gl/mapbox";
import { ScatterplotLayer, ArcLayer } from "@deck.gl/layers";

import useTimeStore from "@/store/useTimeStore";
import type { UIPayload, NodeEntry, EdgeEntry } from "@/types/payload";

// Newcastle upon Tyne city centre
const INITIAL_VIEW = {
  longitude: -1.6178,
  latitude: 54.9783,
  zoom: 11,
  pitch: 45,
  bearing: 0,
};

const MAP_STYLE =
  "https://basemaps.cartocdn.com/gl/dark-matter-gl-style/style.json";

// Defensive cap on the global edge set when no node is selected. With ego-graph
// isolation active, ALL edges touching the selected node are shown regardless.
const GLOBAL_EDGE_CAP = 80;

/**
 * Maps a normalised value t∈[0,1] to a Green→Yellow→Red RGBA tuple.
 * t=0 → dim green, t=0.5 → yellow, t=1 → red.
 */
function heatColor(t: number): [number, number, number, number] {
  const c = Math.min(1, Math.max(0, t));
  if (c < 0.5) {
    const s = c * 2; // 0→1
    return [Math.round(s * 255), 200, 0, 220];
  }
  const s = (c - 0.5) * 2; // 0→1
  return [255, Math.round(200 * (1 - s)), 0, 220];
}

function nodeFillColor(d: NodeEntry, timestep: number): [number, number, number, number] {
  const entry = d.timeseries[timestep];
  if (!entry) return [128, 128, 128, 180];
  const maxUncertainty = 50;
  const normalized = Math.min(1, entry.uncertainty / maxUncertainty);
  return heatColor(normalized);
}

function nodeRadius(d: NodeEntry, timestep: number): number {
  const entry = d.timeseries[timestep];
  const base = d.is_simulated ? 4 : 2;
  if (!entry) return base;
  return base + entry.prediction;
}

interface FilterState {
  selectedNodeId: number | null;
  attentionThreshold: number;
}

/**
 * Construct ScatterplotLayers (real + simulated) and an ArcLayer for the given
 * payload snapshot. Ego-graph isolation: when selectedNodeId is set, only edges
 * incident to that node are kept.
 */
function buildLayers(
  payload: UIPayload,
  nodeMap: Map<number, NodeEntry>,
  timestep: number,
  filters: FilterState,
  onSelectNode: (id: number | null) => void,
) {
  const { selectedNodeId, attentionThreshold } = filters;

  // ── Real-node layer (solid filled disc) ────────────────────────────────────
  const realNodes = payload.nodes.filter((n) => !n.is_simulated);
  const realLayer = new ScatterplotLayer<NodeEntry>({
    id: "nodes-real",
    data: realNodes,
    getPosition: (d) => [d.lon, d.lat],
    getFillColor: (d) => nodeFillColor(d, timestep),
    getRadius: (d) => nodeRadius(d, timestep),
    radiusUnits: "meters",
    stroked: false,
    filled: true,
    pickable: true,
    onClick: ({ object }) => onSelectNode(object ? object.id : null),
    updateTriggers: {
      getFillColor: [timestep],
      getRadius: [timestep],
    },
  });

  // ── Simulated-node layer (hollow ring) ─────────────────────────────────────
  // FRONTEND_ARCHITECTURE.md §A: simulated nodes must be visually distinct.
  // Deck.gl's stroked/filled flags are layer-wide, so we split into two layers.
  const simNodes = payload.nodes.filter((n) => n.is_simulated);
  const simLayer = new ScatterplotLayer<NodeEntry>({
    id: "nodes-simulated",
    data: simNodes,
    getPosition: (d) => [d.lon, d.lat],
    // Ring inherits the same uncertainty heat colour for visual coherence.
    getLineColor: (d) => nodeFillColor(d, timestep),
    getRadius: (d) => nodeRadius(d, timestep),
    radiusUnits: "meters",
    stroked: true,
    filled: false,
    lineWidthMinPixels: 3,
    pickable: true,
    onClick: ({ object }) => onSelectNode(object ? object.id : null),
    updateTriggers: {
      getLineColor: [timestep],
      getRadius: [timestep],
    },
  });

  // ── Topology Layer (attention arcs) ────────────────────────────────────────
  type WeightedEdge = { edge: EdgeEntry; weight: number };
  let weighted: WeightedEdge[] = payload.edges
    .map((e) => ({ edge: e, weight: e.attention_sequence[timestep] ?? 0 }))
    .filter((x) => x.weight >= attentionThreshold);

  if (selectedNodeId !== null) {
    // Ego-graph: keep only edges touching the selected node.
    weighted = weighted.filter(
      (x) =>
        x.edge.source === selectedNodeId || x.edge.target === selectedNodeId,
    );
  } else {
    // Defensive cap to prevent visual hairball when nothing is selected.
    weighted = weighted
      .sort((a, b) => b.weight - a.weight)
      .slice(0, GLOBAL_EDGE_CAP);
  }

  const arcLayer = new ArcLayer<WeightedEdge>({
    id: "topology-layer",
    data: weighted,
    getSourcePosition: (d) => {
      const src = nodeMap.get(d.edge.source);
      return src ? [src.lon, src.lat] : [0, 0];
    },
    getTargetPosition: (d) => {
      const tgt = nodeMap.get(d.edge.target);
      return tgt ? [tgt.lon, tgt.lat] : [0, 0];
    },
    getSourceColor: (d) => [255, 165, 0, Math.round(d.weight * 255)],
    getTargetColor: (d) => [255, 69, 0, Math.round(d.weight * 255)],
    getWidth: (d) => Math.max(1, d.weight * 80),
    updateTriggers: {
      getSourceColor: [timestep],
      getTargetColor: [timestep],
      getWidth: [timestep],
      data: [timestep, selectedNodeId, attentionThreshold],
    },
  });

  return [realLayer, simLayer, arcLayer];
}

export default function MapVisualizer() {
  const mapContainerRef = useRef<HTMLDivElement>(null);
  const mapRef = useRef<maplibregl.Map | null>(null);
  const overlayRef = useRef<MapboxOverlay | null>(null);

  const payloadRef = useRef<UIPayload | null>(null);
  const nodeMapRef = useRef<Map<number, NodeEntry>>(new Map());

  const setSelectedNodeId = useTimeStore((s) => s.setSelectedNodeId);
  const currentTimestep = useTimeStore((s) => s.currentTimestep);
  const selectedNodeId = useTimeStore((s) => s.selectedNodeId);

      zoom: INITIAL_VIEW.zoom,
      pitch: INITIAL_VIEW.pitch,
      bearing: INITIAL_VIEW.bearing,
    });

    map.addControl(new maplibregl.NavigationControl(), "top-right");

    const overlay = new MapboxOverlay({ layers: [] });
    map.addControl(overlay as unknown as maplibregl.IControl);

    mapRef.current = map;
    overlayRef.current = overlay;

    // Click on empty map area → deselect node (Deck.gl onClick fires first when
    // a pickable object is hit, so this only runs on background clicks).
    map.on("click", () => {
      if (useTimeStore.getState().selectedNodeId !== null) {
        useTimeStore.getState().setSelectedNodeId(null);
      }
    });

    map.on("load", async () => {
      try {
        const res = await fetch("/data/ui_payload.json");
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const payload: UIPayload = await res.json();

        setMaxTimesteps(payload.metadata.timesteps - 1);

        const nodeMap = new Map<number, NodeEntry>();
        for (const node of payload.nodes) nodeMap.set(node.id, node);

        payloadRef.current = payload;
        nodeMapRef.current = nodeMap;

        const simNodes = payload.nodes.filter((n) => n.is_simulated);
        console.info(
          `[MapVisualizer] Payload loaded: ${payload.nodes.length} nodes` +
            ` (${payload.metadata.num_real_nodes} real + ${simNodes.length} simulated),` +
            ` ${payload.edges.length} edges, ${payload.metadata.timesteps} timesteps.`,
        );

        const state = useTimeStore.getState();
        overlay.setProps({
          layers: buildLayers(
            payload,
            nodeMap,
            state.currentTimestep,
            {
              selectedNodeId: state.selectedNodeId,
              attentionThreshold: state.attentionThreshold,
            },
            setSelectedNodeId,
          ),
        });
      } catch (err) {
        console.warn("[MapVisualizer] Failed to load ui_payload.json", err);
      }
    });

    return () => {
      overlay.finalize();
      map.remove();
      mapRef.current = null;
      overlayRef.current = null;
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  // Rebuild layers whenever the timestep, selection, or threshold changes.
  useEffect(() => {
    const payload = payloadRef.current;
    const overlay = overlayRef.current;
    if (!payload || !overlay) return;
    overlay.setProps({
      layers: buildLayers(
        payload,
        nodeMapRef.current,
        currentTimestep,
        { selectedNodeId, attentionThreshold },
        setSelectedNodeId,
      ),
    });
  }, [currentTimestep, selectedNodeId, attentionThreshold, setSelectedNodeId]);

  return (
    <div
      ref={mapContainerRef}
      style={{ width: "100%", height: "100%" }}
      aria-label="Geospatial digital twin map"
    />
  );
}

"use client";

import { useEffect, useMemo, useRef, useState } from "react";
import useTimeStore from "@/store/useTimeStore";
import type { UIPayload, NodeEntry } from "@/types/payload";

// SVG plot dimensions (purely visual; no responsive resize needed for Phase 1).
const PLOT_W = 320;
const PLOT_H = 140;
const PAD = { top: 8, right: 8, bottom: 18, left: 30 };
const INNER_W = PLOT_W - PAD.left - PAD.right;
const INNER_H = PLOT_H - PAD.top - PAD.bottom;

interface ChartProps {
  node: NodeEntry;
  currentTimestep: number;
}

function NodeChart({ node, currentTimestep }: ChartProps) {
  const T = node.imputed_series.length;

  // Stable scales: combine ground-truth (filtering nulls) and imputed values.
  const { yMin, yMax } = useMemo(() => {
    const vals: number[] = [];
    for (const v of node.ground_truth_series) if (v !== null) vals.push(v);
    for (const v of node.imputed_series) vals.push(v);
    if (vals.length === 0) return { yMin: 0, yMax: 1 };
    const lo = Math.min(...vals);
    const hi = Math.max(...vals);
    // Pad 5% top/bottom so peaks aren't flush with the frame.
    const span = Math.max(1, hi - lo) * 0.05;
    return { yMin: Math.max(0, lo - span), yMax: hi + span };
  }, [node]);

  const xOf = (t: number) => PAD.left + (T <= 1 ? 0 : (t / (T - 1)) * INNER_W);
  const yOf = (v: number) =>
    PAD.top + INNER_H - ((v - yMin) / (yMax - yMin || 1)) * INNER_H;

  // Build polyline strings; gaps in ground truth (null) split the line.
  const gtSegments = useMemo(() => {
    const segs: string[] = [];
    let cur: string[] = [];
    for (let t = 0; t < T; t++) {
      const v = node.ground_truth_series[t];
      if (v === null || v === undefined) {
        if (cur.length) segs.push(cur.join(" "));
        cur = [];
      } else {
        cur.push(`${xOf(t)},${yOf(v)}`);
      }
    }
    if (cur.length) segs.push(cur.join(" "));
    return segs;
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [node, yMin, yMax]);

  const imputedPoints = useMemo(() => {
    return node.imputed_series.map((v, t) => `${xOf(t)},${yOf(v)}`).join(" ");
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [node, yMin, yMax]);

  // Highlight bands behind masked timesteps so the user sees what was healed.
  const maskBands = useMemo(() => {
    const bandW = T <= 1 ? INNER_W : INNER_W / (T - 1);
    return node.mask_series
      .map((m, t) => (m ? t : -1))
      .filter((t) => t >= 0)
      .map((t) => ({
        x: xOf(t) - bandW / 2,
        w: bandW,
      }));
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [node]);

  const cursorX = xOf(currentTimestep);

  return (
    <svg
      width={PLOT_W}
      height={PLOT_H}
      viewBox={`0 0 ${PLOT_W} ${PLOT_H}`}
      role="img"
      aria-label={`Imputation chart for ${node.location_name}`}
    >
      {/* Mask highlight bands */}
      {maskBands.map((b, i) => (
        <rect
          key={i}
          x={b.x}
          y={PAD.top}
          width={b.w}
          height={INNER_H}
          fill="rgba(255, 99, 132, 0.18)"
        />
      ))}

      {/* Plot frame */}
      <rect
        x={PAD.left}
        y={PAD.top}
        width={INNER_W}
        height={INNER_H}
        fill="none"
        stroke="rgba(255,255,255,0.2)"
      />

      {/* Y-axis ticks */}
      <text
        x={PAD.left - 4}
        y={PAD.top + 4}
        fill="rgba(255,255,255,0.6)"
        fontSize="9"
        textAnchor="end"
      >
        {yMax.toFixed(1)}
      </text>
      <text
        x={PAD.left - 4}
        y={PAD.top + INNER_H}
        fill="rgba(255,255,255,0.6)"
        fontSize="9"
        textAnchor="end"
      >
        {yMin.toFixed(1)}
      </text>

      {/* X-axis labels */}
      <text
        x={PAD.left}
        y={PLOT_H - 4}
        fill="rgba(255,255,255,0.6)"
        fontSize="9"
      >
        t=0
      </text>
      <text
        x={PAD.left + INNER_W}
        y={PLOT_H - 4}
        fill="rgba(255,255,255,0.6)"
        fontSize="9"
        textAnchor="end"
      >
        t={T - 1}
      </text>

      {/* Imputed series (orange) */}
      <polyline
        points={imputedPoints}
        fill="none"
        stroke="rgb(255, 165, 0)"
        strokeWidth="1.5"
      />

      {/* Ground truth segments (blue), skipped where null */}
      {gtSegments.map((seg, i) => (
        <polyline
          key={i}
          points={seg}
          fill="none"
          stroke="rgb(96, 165, 250)"
          strokeWidth="1.5"
        />
      ))}

      {/* Current-timestep cursor */}
      <line
        x1={cursorX}
        y1={PAD.top}
        x2={cursorX}
        y2={PAD.top + INNER_H}
        stroke="rgba(255,255,255,0.55)"
        strokeWidth="1"
        strokeDasharray="2 2"
      />
    </svg>
  );
}

'use client';

import { useEffect, useRef, useCallback } from 'react';
import useTimeStore from '@/store/useTimeStore';

// Each timestep represents 15 minutes; anchor to midnight of the test day.
function timestepToLabel(t: number): string {
  const totalMinutes = t * 15;
  const hh = Math.floor(totalMinutes / 60)
    .toString()
    .padStart(2, '0');
  const mm = (totalMinutes % 60).toString().padStart(2, '0');
  return `${hh}:${mm}`;
}

export default function TimeSlider() {
  const currentTimestep = useTimeStore((s) => s.currentTimestep);
  const maxTimesteps = useTimeStore((s) => s.maxTimesteps);
  const isPlaying = useTimeStore((s) => s.isPlaying);
  const setTimestep = useTimeStore((s) => s.setTimestep);
  const togglePlayback = useTimeStore((s) => s.togglePlayback);
  const incrementTimestep = useTimeStore((s) => s.incrementTimestep);

  // Log every timestep change so the test can be verified in the console
  useEffect(() => {
    console.log(`[TimeSlider] currentTimestep=${currentTimestep}  (${timestepToLabel(currentTimestep)})`);
  }, [currentTimestep]);

  // Playback animation loop
  const rafRef = useRef<number | null>(null);
  const lastTickRef = useRef<number>(0);
  const TICK_INTERVAL_MS = 300; // one step every 300 ms

  const animate = useCallback(
    (now: number) => {
      if (now - lastTickRef.current >= TICK_INTERVAL_MS) {
        incrementTimestep();
        lastTickRef.current = now;
      }
      rafRef.current = requestAnimationFrame(animate);
    },
    [incrementTimestep]
  );

  useEffect(() => {
    if (isPlaying) {
      lastTickRef.current = performance.now();
      rafRef.current = requestAnimationFrame(animate);
    } else {
      if (rafRef.current !== null) {
        cancelAnimationFrame(rafRef.current);
        rafRef.current = null;
      }
    }
    return () => {
      if (rafRef.current !== null) {
        cancelAnimationFrame(rafRef.current);
      }
    };
  }, [isPlaying, animate]);

  return (
    <div
      className="
        absolute bottom-6 left-1/2 -translate-x-1/2
        flex flex-col items-center gap-2
        bg-black/70 backdrop-blur-sm text-white
        rounded-xl px-6 py-4 shadow-2xl
        w-[min(560px,90vw)]
        z-10
      "
      aria-label="Time navigation controls"
    >
      {/* Header row */}
      <div className="flex w-full items-center justify-between text-xs font-mono text-slate-300">
        <span>2024-05-10</span>
        <span className="text-base font-semibold text-white tabular-nums">
          {timestepToLabel(currentTimestep)}
        </span>
        <span>
          t = {currentTimestep} / {maxTimesteps}
        </span>
      </div>

      {/* Slider */}
      <input
        type="range"
        min={0}
        max={maxTimesteps}
        value={currentTimestep}
        onChange={(e) => setTimestep(Number(e.target.value))}
        className="w-full h-2 appearance-none rounded-full cursor-pointer accent-orange-400"
        aria-label="Timestep selector"
      />

      {/* Tick marks for every 4 steps (= 1 hour) */}
      <div className="flex w-full justify-between px-0.5">
        {Array.from({ length: 7 }, (_, i) => (
          <span key={i} className="text-[10px] text-slate-400 font-mono">
            {String(i * 4).padStart(2, '0')}h
          </span>
        ))}
      </div>

      {/* Play / Pause */}
      <button
        onClick={togglePlayback}
        className="
          mt-1 px-5 py-1.5 rounded-full text-sm font-medium
          bg-orange-500 hover:bg-orange-400 active:bg-orange-600
          transition-colors focus:outline-none focus:ring-2 focus:ring-orange-300
        "
        aria-label={isPlaying ? 'Pause playback' : 'Play time animation'}

  );

import { create } from 'zustand';

interface TimeState {
  currentTimestep: number;
  maxTimesteps: number;
  isPlaying: boolean;
  selectedNodeId: number | null;
  attentionThreshold: number;

  setTimestep: (step: number) => void;
  setMaxTimesteps: (max: number) => void;
  togglePlayback: () => void;
  incrementTimestep: () => void;
  setSelectedNodeId: (id: number | null) => void;
  setAttentionThreshold: (v: number) => void;
}

const useTimeStore = create<TimeState>((set, get) => ({
  currentTimestep: 0,
  maxTimesteps: 95,
  isPlaying: false,
  selectedNodeId: null,
  attentionThreshold: 0.05,

  setTimestep: (step: number) =>
    set({ currentTimestep: Math.max(0, Math.min(step, get().maxTimesteps)) }),

  setMaxTimesteps: (max: number) => set({ maxTimesteps: max }),

  togglePlayback: () => set((state) => ({ isPlaying: !state.isPlaying })),

  incrementTimestep: () =>
    set((state) => ({
      currentTimestep:
        state.currentTimestep >= state.maxTimesteps
          ? 0
          : state.currentTimestep + 1,
    })),

  setSelectedNodeId: (id: number | null) => set({ selectedNodeId: id }),

  // Clamp threshold to [0, 1] — attention weights live in [0, 1].
  setAttentionThreshold: (v: number) =>
    set({ attentionThreshold: Math.max(0, Math.min(1, v)) }),
}));

export default useTimeStore;

import torch
from torch.utils.data import Dataset, DataLoader
import numpy as np
import pandas as pd
import logging
from sklearn.preprocessing import StandardScaler

# Standard random seed initialization
np.random.seed(42)
torch.manual_seed(42)

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)

class RealIoTDataset(Dataset):
    """
    Production PyTorch Dataset for the ResilientIoTPipeline.
    Loads real parquet data efficiently using memory-friendly time filters.
    Groups data by location, applies sliding window extraction, and injects NaN masking.
    """
    def __init__(self, 
                 parquet_path: str, 
                 start_date: str, 
                 end_date: str, 
                 seq_len: int = 12, 
                 mask_prob: float = 0.15,
                 target_veh_class: str = 'person',
                 target_dir: str = 'all'):
        
        logger.info(f"Loading data from {parquet_path} between {start_date} and {end_date}")
        
        # 1. Load Data with Time Filter Constraints
        start_dt = pd.Timestamp(start_date)
        end_dt = pd.Timestamp(end_date)
        
        df = pd.read_parquet(
            parquet_path,
            filters=[
                ('dt', '>=', start_dt), 
                ('dt', '<', end_dt)
            ],
            columns=['dt', 'location', 'value', 'Humidity', 'Solar Radiation', 'nearby_poi_count', 'dist_to_nearest_intersection', 'veh_class', 'dir']
        )
        
        if df.empty:
            raise ValueError(f"No data found for the specified date range: {start_date} to {end_date}")

        available_classes = sorted(df['veh_class'].dropna().astype(str).unique().tolist())
        available_dirs = sorted(df['dir'].dropna().astype(str).unique().tolist())
            
        # 2. Filter target stream to ensure unique (dt, location) indices
        df = df[df['veh_class'] == target_veh_class]
        if df.empty:
            raise ValueError(
                f"No rows after veh_class filter. Requested veh_class='{target_veh_class}' "
                f"for range {start_date} to {end_date}. Available veh_class values: {available_classes}"
            )
        
        if target_dir == 'all':
            # Group by dt and location, sum values, take first for weather/static features
            agg_funcs = {
                'value': 'sum',
                'Humidity': 'first',
                'Solar Radiation': 'first',
                'nearby_poi_count': 'first',
                'dist_to_nearest_intersection': 'first'
            }
            df = df.groupby(['dt', 'location'], as_index=False).agg(agg_funcs)
        else:
            df = df[df['dir'] == target_dir]
            if df.empty:
                raise ValueError(
                    f"No rows after dir filter. Requested dir='{target_dir}' with veh_class='{target_veh_class}' "
                    f"for range {start_date} to {end_date}. Available dir values before filtering: {available_dirs}"
                )

        if df.empty:
            raise ValueError(
                f"No rows available after filtering and aggregation for range {start_date} to {end_date}, "
                f"veh_class='{target_veh_class}', dir='{target_dir}'."
            )
            
        # 3. Extract dimensions
        self.locations = sorted(df['location'].unique())
        self.times = sorted(df['dt'].unique())
        self.seq_len = seq_len
        self.mask_prob = mask_prob
        self.num_nodes = len(self.locations)
        
        logger.info(f"Loaded {len(self.times)} timesteps across {self.num_nodes} locations for class={target_veh_class}, dir={target_dir}.")
        
        # 4. Pivot for Sliding Window Logic
        df = df.set_index(['dt', 'location'])
        
        # Dynamic features
        dyn_df = df[['value', 'Humidity', 'Solar Radiation']].unstack('location')
        locations_idx = pd.Index(self.locations, name='location')
        
        val_arr = dyn_df['value'].reindex(columns=locations_idx).fillna(0.0).values
        hum_arr = dyn_df['Humidity'].reindex(columns=locations_idx).fillna(0.0).values
        sol_arr = dyn_df['Solar Radiation'].reindex(columns=locations_idx).fillna(0.0).values

        # Preserve a raw, unscaled copy of traffic counts BEFORE any scaling.
        # ZINB NLL requires non-negative counts as targets; StandardScaler would
        # convert these to signed floats and corrupt the loss domain.
        self.unscaled_traffic = val_arr.copy()  # [num_times, num_nodes]

        # [num_times, num_nodes, 3]
        self.dynamic_data = np.stack([val_arr, hum_arr, sol_arr], axis=-1)
        self.time_series_dim = self.dynamic_data.shape[-1]

        # Scale dynamic features across the full dataset so the model receives
        # zero-mean, unit-variance inputs — critical for stable gradient flow.
        num_times, num_nodes_d, n_dyn_features = self.dynamic_data.shape
        dyn_flat = self.dynamic_data.reshape(-1, n_dyn_features)
        self.scaler = StandardScaler()
        dyn_scaled = self.scaler.fit_transform(dyn_flat)
        self.dynamic_data = dyn_scaled.reshape(num_times, num_nodes_d, n_dyn_features)
        logger.info(f"Dynamic features scaled: mean≈0, std≈1 over {num_times * num_nodes_d} samples.")

        # Static features
        stat_df = df[['nearby_poi_count', 'dist_to_nearest_intersection']].groupby('location').first()
        stat_df = stat_df.reindex(locations_idx).fillna(0.0)

        # Scale static features so DynamicGraphLearner receives normalised coordinates/metadata.
        stat_np = stat_df.values  # [num_nodes, static_feat_dim]
        self.static_scaler = StandardScaler()
        stat_np_scaled = self.static_scaler.fit_transform(stat_np)
        self.static_features = torch.tensor(stat_np_scaled, dtype=torch.float32)
        self.static_feat_dim = self.static_features.shape[-1]
        logger.info(f"Static features scaled: mean≈0, std≈1 over {stat_np.shape[0]} nodes.")
        
        logger.info(f"Feature dimensions established. Static: {self.static_feat_dim}, Dynamic: {self.time_series_dim}")

    def __len__(self) -> int:
        return max(0, len(self.times) - self.seq_len)

    def __getitem__(self, idx: int) -> dict:
        # Extract sliding window
        # Dynamic: [seq_len, num_nodes, D] -> permute -> [num_nodes, seq_len, D]
        dyn_slice = self.dynamic_data[idx : idx + self.seq_len]
        dyn_slice = np.transpose(dyn_slice, (1, 0, 2))
        
        dyn_tensor = torch.tensor(dyn_slice, dtype=torch.float32)

        # Forecast target: pull from unscaled traffic counts, not scaled dynamic_data.
        # clamp(min=0) is a hard tripwire — raw counts must never be negative,
        # but guards against any residual float precision artifacts from the parquet.
        target = self.unscaled_traffic[idx + self.seq_len]  # [num_nodes]
        target_tensor = torch.tensor(target, dtype=torch.float32).clamp(min=0)
        
        # 4. Dynamic Masking logic (~15% artificial NaN injection)
        node_mask = torch.rand_like(dyn_tensor) < self.mask_prob
        target_impute = dyn_tensor.clone()
        dyn_masked = dyn_tensor.clone()
        dyn_masked[node_mask] = float('nan')

        return {
            'static_features': self.static_features,
            'dynamic_features': dyn_masked,
            'target_impute': target_impute,
            'target_forecast': target_tensor,
            'node_mask': node_mask
        }

import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Tuple, Optional

class DecoupledDecoders(nn.Module):
    """
    DecoupledDecoders: Multi-task heads for imputation and uncertainty-aware forecasting.
    """
    def __init__(self, hidden_dim: int, time_series_dim: int):
        super(DecoupledDecoders, self).__init__()

        # Reproducibility
        torch.manual_seed(42)

        self.hidden_dim = hidden_dim
        self.time_series_dim = time_series_dim

        # Imputation Decoder: Reconstructs the entire sequence.
        # Deepened to a 2-layer MLP to give the model enough capacity to recover
        # masked sensor readings from the latent graph representation.
        self.impute_layer = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 2),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim * 2, time_series_dim)
        )

        # Forecasting Decoder: Predicts ZINB parameters (mu, theta, pi).
        # Deepened to match imputation head capacity and reduce gradient starvation.
        self.forecast_layer = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 2),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim * 2, 3)
        )

    def forward(self, latent_embeddings: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor]:
        """
        Args:
            latent_embeddings: [batch_size, num_nodes, seq_len, hidden_dim]
        Returns:
            imputed_features: [batch_size, num_nodes, seq_len, time_series_dim]
            mu: [batch_size, num_nodes]
            theta: [batch_size, num_nodes]
            pi: [batch_size, num_nodes]
        """
        assert latent_embeddings.dim() == 4, f"Expected 4D embeddings, got {latent_embeddings.shape}"
        batch_size, num_nodes, seq_len, hidden_dim = latent_embeddings.shape

        # 1. Imputation (across all time steps)
        imputed_features = self.impute_layer(latent_embeddings)

        # 2. Forecasting (using the final time step's embedding)
        last_step_embedding = latent_embeddings[:, :, -1, :] # [batch_size, num_nodes, hidden_dim]
        forecast_logits = self.forecast_layer(last_step_embedding) # [batch_size, num_nodes, 3]

        # Split raw logits
        mu_logits = forecast_logits[:, :, 0]
        theta_logits = forecast_logits[:, :, 1]
        pi_logits = forecast_logits[:, :, 2]

        # Apply ZINB constraints (Tripwires from BACKEND_ARCHITECTURE.md)
        eps = 1e-6
        pi = torch.sigmoid(pi_logits)
        mu = F.softplus(mu_logits) + eps
        theta = F.softplus(theta_logits) + eps

        return imputed_features, mu, theta, pi

def compute_zinb_nll(y_true: torch.Tensor, mu: torch.Tensor, theta: torch.Tensor, pi: torch.Tensor) -> torch.Tensor:
    """
    Negative Log-Likelihood for Zero-Inflated Negative Binomial Distribution.

    Formula:
    If y=0: P(y) = pi + (1-pi) * (theta / (theta + mu))^theta
    If y>0: P(y) = (1-pi) * [Gamma(y+theta)/(y!Gamma(theta))] * (theta/(theta+mu))^theta * (mu/(theta+mu))^y
    """
    eps = 1e-6
    y_true = y_true.float()

    # Clamp log operations to eps
    def safe_log(x):
        return torch.log(x.clamp(min=eps))

    # NB log-likelihood components
    # log(theta / (theta + mu))
    log_theta_mu_ratio = safe_log(theta) - safe_log(theta + mu)
    # log(mu / (theta + mu))
    log_mu_mu_ratio = safe_log(mu) - safe_log(theta + mu)

    # Case y > 0
    # log P(y|NB) = logGamma(y+theta) - logGamma(y+1) - logGamma(theta) + theta*log(theta/(theta+mu)) + y*log(mu/(theta+mu))
    ll_nb = (torch.lgamma(y_true + theta)
             - torch.lgamma(y_true + 1)
             - torch.lgamma(theta)
             + theta * log_theta_mu_ratio
             + y_true * log_mu_mu_ratio)

    # Case y = 0
    # P(y=0|ZINB) = pi + (1-pi) * exp(theta * log(theta/(theta+mu)))
    # For numerical stability, we use log-sum-exp or handle it carefully
    # log_p_zero_nb = theta * log_theta_mu_ratio
    ll_zero = safe_log(pi + (1 - pi) * torch.exp(theta * log_theta_mu_ratio))

    # Case y > 0 (ZINB)
    # log P(y|ZINB) = log(1-pi) + ll_nb
    ll_nonzero = safe_log(1 - pi) + ll_nb

    # Combine cases
    result = torch.where(y_true < eps, ll_zero, ll_nonzero)

    return -torch.mean(result)

def compute_loss(imputed_features: torch.Tensor,
                 target_impute: torch.Tensor,
                 mu: torch.Tensor,
                 theta: torch.Tensor,
                 pi: torch.Tensor,
                 target_forecast: torch.Tensor,
                 w_impute: float = 1.0,
                 w_forecast: float = 1.0) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    Joint Loss: MSE for Imputation + ZINB NLL for Forecasting.
    """
    # 1. Imputation Loss (MSE)
    # BACKEND_ARCHITECTURE.md: "strictly on the artificially masked nodes"
    # Note: In a real scenario, we'd use a mask here.
    loss_impute = F.mse_loss(imputed_features, target_impute)

    # 2. Forecasting Loss (ZINB NLL)
    loss_forecast = compute_zinb_nll(target_forecast, mu, theta, pi)

    # 3. Total Weighted Loss
    total_loss = (w_impute * loss_impute) + (w_forecast * loss_forecast)

    # --- Tripwires (Rule 5 & BACKEND_ARCHITECTURE.md) ---
    if torch.isnan(total_loss).any():
        # Print stats for debugging before crashing
        print(f"DEBUG: mu min={mu.min()}, max={mu.max()}")
        print(f"DEBUG: theta min={theta.min()}, max={theta.max()}")
        print(f"DEBUG: pi min={pi.min()}, max={pi.max()}")
        raise ValueError("CRITICAL FAILURE: Loss is NaN. Mathematical tripwire triggered.")

    return total_loss, loss_impute, loss_forecast

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GATv2Conv
from typing import Optional, Tuple, Union

class MaskedSpatiotemporalEncoder(nn.Module):
    """
    MaskedSpatiotemporalEncoder: Processes dynamic IoT data using GATv2 and Transformers.
    
    Architecture:
    1. Spatial: GATv2Conv layers applied independently across each time step.
    2. Temporal: TransformerEncoder to capture dependencies across the sequence.
    """
    def __init__(self, 
                 num_nodes: int, 
                 seq_len: int, 
                 time_series_dim: int, 
                 hidden_dim: int = 64, 
                 num_heads: int = 4, 
                 num_layers: int = 2,
                 dropout: float = 0.1):
        super(MaskedSpatiotemporalEncoder, self).__init__()
        
        # Reproducibility at initialization
        torch.manual_seed(42)
        
        self.num_nodes = num_nodes
        self.seq_len = seq_len
        self.time_series_dim = time_series_dim
        self.hidden_dim = hidden_dim

        # 1. Spatial Processing: GATv2Conv
        # We use a single layer for simplicity as per common IoT patterns, 
        # or can be extended to multiple.
        self.gat = GATv2Conv(
            in_channels=time_series_dim,
            out_channels=hidden_dim // num_heads,
            heads=num_heads,
            dropout=dropout,
            edge_dim=1 # For edge_weight
        )

        # 2. Temporal Processing: Transformer
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_dim,
            nhead=num_heads,
            dim_feedforward=hidden_dim * 4,
            dropout=dropout,
            batch_first=False # Standard Transformer [Seq, Batch, Dim]
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)

    def forward(
        self,
        dynamic_features: torch.Tensor,
        edge_index: torch.Tensor,
        edge_weight: torch.Tensor,
        return_attention_weights: bool = False,
    ) -> Union[torch.Tensor, Tuple[torch.Tensor, torch.Tensor]]:
        """
        Args:
            dynamic_features: [batch_size, num_nodes, seq_len, time_series_dim]
            edge_index: [2, E]
            edge_weight: [E]
            return_attention_weights: If True, also return the GAT attention
                coefficients alpha [batched_E, num_heads] for downstream analysis.
        Returns:
            latent_embeddings: [batch_size, num_nodes, seq_len, hidden_dim]
            alpha (optional): [batched_E, num_heads] — only when return_attention_weights=True.
        """
        # --- Defensive Data Handling (Rule 2) ---
        assert dynamic_features.dim() == 4, f"Expected 4D features, got {dynamic_features.shape}"
        batch_size, num_nodes, seq_len, ts_dim = dynamic_features.shape
        assert num_nodes == self.num_nodes, f"Node mismatch: {num_nodes} != {self.num_nodes}"
        assert seq_len == self.seq_len, f"Seq mismatch: {seq_len} != {self.seq_len}"
        assert ts_dim == self.time_series_dim, f"Feature mismatch: {ts_dim} != {self.time_series_dim}"

        # --- Spatial Processing ---
        # Reshape to [B, T, N, D] then to [B*T*N, D]
        # We want to apply GAT to each (batch, time_step) independently.
        x = dynamic_features.permute(0, 2, 1, 3).contiguous() # [B, T, N, D]
        x = x.view(batch_size * seq_len * num_nodes, ts_dim)

        # Construct batched edge_index
        # Original edge_index is [2, E] for num_nodes.
        # We need to repeat it batch_size * seq_len times with offsets.
        num_graphs = batch_size * seq_len
        E = edge_index.shape[1]
        
        # [2, E * num_graphs]
        batched_edge_index = edge_index.repeat(1, num_graphs)
        offsets = torch.arange(num_graphs, device=edge_index.device).view(-1, 1) * num_nodes
        # offsets shape: [num_graphs, 1]. Repeat for each edge in the graph.
        offsets = offsets.repeat(1, E).view(-1) # [num_graphs * E]
        batched_edge_index = batched_edge_index + offsets
        
        # edge_weight also needs repeating
        batched_edge_weight = edge_weight.repeat(num_graphs)

        # Apply GAT — optionally collect attention coefficients for analysis.
        if return_attention_weights:
            # PyG returns (out, (edge_index_used, alpha)) when return_attention_weights=True
            x_spatial, (_, alpha) = self.gat(
                x, batched_edge_index,
                edge_attr=batched_edge_weight,
                return_attention_weights=True,
            )
        else:
            x_spatial = self.gat(x, batched_edge_index, edge_attr=batched_edge_weight)
            alpha = None

        # --- Temporal Processing ---
        # Reshape back to [B, T, N, H]
        x_temporal = x_spatial.view(batch_size, seq_len, num_nodes, self.hidden_dim)
        
        # Transformer expects [Seq, Batch, Dim]
        # We treat each node in each batch as an independent sequence.
        # Batch dimension for Transformer: B * N
        # Seq dimension: T
        x_temporal = x_temporal.permute(1, 0, 2, 3).contiguous() # [T, B, N, H]
        x_temporal = x_temporal.view(seq_len, batch_size * num_nodes, self.hidden_dim)

        # Pass through Transformer
        # x_out: [T, B * N, H]
        x_out = self.transformer(x_temporal)

        # Reshape back to [B, N, T, H]
        x_out = x_out.view(seq_len, batch_size, num_nodes, self.hidden_dim)
        x_out = x_out.permute(1, 2, 0, 3).contiguous() # [B, N, T, H]

        # --- Tripwires (Rule 5) ---
        if torch.isnan(x_out).any():
            raise ValueError("NaN detected in MaskedSpatiotemporalEncoder output!")

        if return_attention_weights:
            return x_out, alpha
        return x_out

def load_sensor_coords(path: str) -> Dict[str, Dict[str, float]]:
    """Return {location_name: {lat, lon}} from traffic_sensors.json."""
    with open(path, "r") as fh:
        raw = json.load(fh)
    return {entry["location"]: {"lat": entry["lat"], "lon": entry["lon"]} for entry in raw}


def build_simulated_static(
    real_static: torch.Tensor,
    n: int,
) -> torch.Tensor:
    """
    Create static features for n simulated nodes.

    Uses the mean of the real nodes' (already-scaled) static features so that
    the graph learner sees plausible, in-distribution embeddings.

    Args:
        real_static: [num_real_nodes, static_feat_dim]
        n: number of simulated nodes to create

    Returns:
        [n, static_feat_dim]
    """
    mean_static = real_static.mean(dim=0, keepdim=True)  # [1, static_feat_dim]
    return mean_static.expand(n, -1)  # [n, static_feat_dim]


def compute_std_dev(mu: torch.Tensor, theta: torch.Tensor) -> torch.Tensor:
    """
    Variance of the Negative Binomial marginal of the ZINB distribution:
        Var = mu + mu² / theta

    Args:
        mu:    [batch_size, num_nodes]  — mean parameter (already softplus'd + eps)
        theta: [batch_size, num_nodes]  — dispersion parameter (already softplus'd + eps)

    Returns:
        std_dev: [batch_size, num_nodes]
    """
    variance = mu + (mu ** 2) / theta
    # Tripwire: variance must be strictly positive (guaranteed by softplus+eps on mu, theta)
    assert (variance > 0).all(), "TRIPWIRE: Non-positive variance detected."
    return torch.sqrt(variance)


def extract_timestep_attention(
    alpha: torch.Tensor,
    num_edges: int,
    seq_len: int,
) -> torch.Tensor:
    """
    Extract per-edge attention for the most recent time step of the sequence.

    The encoder batches (batch_size × seq_len) graphs end-to-end.  With
    batch_size=1 the layout is:
        alpha[0          : E]        → (sample 0, t=0)
        alpha[E          : 2E]       → (sample 0, t=1)
        …
        alpha[(T-1)*E    : T*E]      → (sample 0, t=T-1)   ← most recent

    We take the last slice and average across attention heads to yield a
    single scalar weight per edge.

    Args:
        alpha:     [(batch_size * seq_len * E), num_heads]
        num_edges: E (edges in the unbatched graph)
        seq_len:   T

    Returns:
        [num_edges]  — mean attention weight per edge for the last time step
    """
    last_slice = alpha[(seq_len - 1) * num_edges : seq_len * num_edges, :]  # [E, num_heads]
    return last_slice.mean(dim=-1)  # [E]

def main() -> None:
    # Reproducibility
    torch.manual_seed(42)
    np.random.seed(42)

    args = parse_args()
    device = torch.device("cpu")  # CPU runner as specified
    logger.info(f"Device: {device}")

    # ------------------------------------------------------------------
    # 1. Load real-world sensor coordinates
    # ------------------------------------------------------------------
    logger.info(f"Loading sensor coordinates from {SENSORS_PATH}")
    sensor_coords = load_sensor_coords(SENSORS_PATH)

    # ------------------------------------------------------------------
    # 2. Load dataset for the test day
    #
    #    Using two-day window (default 2024-05-09 → 2024-05-11) so that
    #    seq_len look-back history exists for day-2 predictions.
    #    Windows for the target day (day 2) start at index:
    #        skip = T_day1 - seq_len   (last seq_len steps of day 1 form context)
    #    where T_day1 ≈ 96 for a full day.
    # ------------------------------------------------------------------
    logger.info(f"Loading dataset: {args.start_date} → {args.end_date}")
    # mask_prob=0.15 (training default) so node_mask + target_impute carry meaningful
    # signal: the model's imputation reconstructs the masked timesteps and the UI
    # can visualise the "self-healing" behaviour at the masked positions.
    dataset = RealIoTDataset(
        parquet_path=PARQUET_PATH,
        start_date=args.start_date,
        end_date=args.end_date,
        seq_len=args.seq_len,
        mask_prob=0.15,
        target_veh_class=args.veh_class,
        target_dir=args.dir,
    )

    # Inverse-transform parameters for channel 0 (traffic count). StandardScaler
    # stores mean_ and scale_ as length-time_series_dim vectors.
    # x_raw = x_scaled * scale_[0] + mean_[0]
    traffic_mean: float = float(dataset.scaler.mean_[0])
    traffic_scale: float = float(dataset.scaler.scale_[0])
    assert traffic_scale > 0, (
        f"TRIPWIRE: dataset.scaler.scale_[0]={traffic_scale} must be > 0 "
        f"to inverse-transform without divergence."
    )
    logger.info(
        f"Traffic-channel inverse-transform: mean={traffic_mean:.4f} "
        f"scale={traffic_scale:.4f}"
    )

    num_nodes_real: int = dataset.num_nodes
    static_feat_dim: int = dataset.static_feat_dim
    time_series_dim: int = dataset.time_series_dim
    num_simulated: int = args.num_simulated
    num_nodes_total: int = num_nodes_real + num_simulated

    logger.info(
        f"Dataset: {len(dataset)} windows | "
        f"real nodes={num_nodes_real} | "
        f"simulated nodes={num_simulated} | "
        f"total nodes={num_nodes_total}"
    )

    # ------------------------------------------------------------------
    # 3. Determine which 96 windows map to the target day (day 2)
    #
    #    total_times = len(dataset) + seq_len
    #    If two days were loaded: total_times ≈ 192.
    #    Windows at indices [skip, skip+96) predict day-2 timestamps.
    #
    #    Fallback: if fewer windows exist, use all available.
    # ------------------------------------------------------------------
    total_times = len(dataset) + args.seq_len
    # Number of timestamps in day 1 is roughly half of total_times
    # (may vary if data is sparse).  We estimate T_day1 as the number of
    # 15-min intervals between start_date and the midpoint.
    half = total_times // 2
    skip = max(0, half - args.seq_len)  # first window whose prediction lands in day 2

    max_windows = min(len(dataset) - skip, NUM_TIMESTEPS_TARGET)
    if max_windows <= 0:
        # Single-day dataset: use all available windows
        skip = 0
        max_windows = min(len(dataset), NUM_TIMESTEPS_TARGET)

    num_timesteps = max_windows
    logger.info(
        f"Using windows [{skip}, {skip + num_timesteps}) "
        f"→ {num_timesteps} inference timesteps"
    )

    # ------------------------------------------------------------------
    # 4. Build combined node metadata list (real + simulated)
    # ------------------------------------------------------------------
    # Real nodes: sorted location names from the dataset
    real_location_names: List[str] = dataset.locations  # already sorted

    nodes_meta: List[Dict] = []
    for i, loc in enumerate(real_location_names):
        coords = sensor_coords.get(loc, {"lat": float("nan"), "lon": float("nan")})
        nodes_meta.append({
            "id": i,
            "location_name": loc,
            "lat": coords["lat"],
            "lon": coords["lon"],
            "is_simulated": False,
        })

    for j in range(num_simulated):
        node_id = num_nodes_real + j
        lat, lon = SIMULATED_NODE_COORDS[j]
        nodes_meta.append({
            "id": node_id,
            "location_name": f"Simulated_Node_{j}",
            "lat": lat,
            "lon": lon,
            "is_simulated": True,
        })

    # ------------------------------------------------------------------
    # 5. Initialise model
    #
    #    Parameters are shape-independent of num_nodes (no per-node
    #    embeddings exist in the architecture), so we can safely
    #    initialise with num_nodes_total and load the checkpoint weights.
    # ------------------------------------------------------------------
    logger.info("Initialising ResilientIoTPipeline …")
    model = ResilientIoTPipeline(
        num_nodes=num_nodes_total,
        static_feat_dim=static_feat_dim,
        time_series_dim=time_series_dim,
        seq_len=args.seq_len,
        embedding_dim=EMBEDDING_DIM,
        hidden_dim=HIDDEN_DIM,
    ).to(device)

    logger.info(f"Loading checkpoint from {CHECKPOINT_PATH}")
    state_dict = torch.load(CHECKPOINT_PATH, map_location=device, weights_only=True)
    model.load_state_dict(state_dict)
    model.eval()
    logger.info("Model loaded and set to eval mode.")

    # ------------------------------------------------------------------
    # 6. Build static features for simulated nodes once (reused every step)
    # ------------------------------------------------------------------
    real_static: torch.Tensor = dataset.static_features.to(device)   # [num_nodes_real, 2]
    sim_static: torch.Tensor = build_simulated_static(real_static, num_simulated)  # [5, 2]
    combined_static: torch.Tensor = torch.cat([real_static, sim_static], dim=0)    # [total, 2]

    assert combined_static.shape == (num_nodes_total, static_feat_dim), \
        f"Static features shape mismatch: {combined_static.shape}"

    # ------------------------------------------------------------------
    # 7. 24-hour inference loop
    # ------------------------------------------------------------------
    # Accumulators — pre-allocate for efficiency
    # timeseries_data[node_id] = list of {t, prediction, uncertainty}
    timeseries_data: List[List[Dict]] = [[] for _ in range(num_nodes_total)]
    # Imputation analytics: three parallel arrays per node, each length=num_timesteps.
    # ground_truth_series uses (number | null) — None for simulated nodes (no physical sensor).
    ground_truth_series: List[List] = [[] for _ in range(num_nodes_total)]
    imputed_series: List[List[float]] = [[] for _ in range(num_nodes_total)]
    mask_series: List[List[bool]] = [[] for _ in range(num_nodes_total)]
    # edge_attention_data: filled once edge topology is known
    edge_attention_data: Dict[Tuple[int, int], List[float]] = {}
    edge_index_cached: torch.Tensor | None = None

    logger.info(f"Starting 24-hour inference loop ({num_timesteps} timesteps) …")

    with torch.no_grad():
        for t, window_idx in enumerate(range(skip, skip + num_timesteps)):
            raw_item = dataset[window_idx]

            # Real node dynamic features: [num_nodes_real, seq_len, time_series_dim]
            real_dynamic: torch.Tensor = raw_item["dynamic_features"].to(device)
            assert real_dynamic.shape == (num_nodes_real, args.seq_len, time_series_dim), \
                f"t={t}: unexpected real_dynamic shape {real_dynamic.shape}"

            # Real node boolean mask: [num_nodes_real, seq_len, time_series_dim]
            real_node_mask: torch.Tensor = raw_item["node_mask"].to(device)
            assert real_node_mask.shape == real_dynamic.shape, (
                f"t={t}: node_mask shape {real_node_mask.shape} != "
                f"dynamic shape {real_dynamic.shape}"
            )

            # Simulated node dynamic features: all NaN → zeros via nan_to_num in pipeline
            sim_dynamic: torch.Tensor = torch.full(
                (num_simulated, args.seq_len, time_series_dim),
                float("nan"),
                device=device,
            )

            # Combined: [num_nodes_total, seq_len, time_series_dim]
            combined_dynamic = torch.cat([real_dynamic, sim_dynamic], dim=0)

            # Add batch dimension: [1, num_nodes_total, seq_len, time_series_dim]
            combined_dynamic = combined_dynamic.unsqueeze(0)

            batch = {
                "static_features": combined_static,
                "dynamic_features": combined_dynamic,
            }

            # Forward pass (analysis mode: returns graph + ZINB params + imputation, no loss)
            result = model(batch, return_analysis=True)

            # -------- ZINB parameters --------
            # mu, theta: [1, num_nodes_total]  (batch_size=1)
            mu: torch.Tensor = result["mu"][0]       # [num_nodes_total]
            theta: torch.Tensor = result["theta"][0]  # [num_nodes_total]
            std_dev: torch.Tensor = compute_std_dev(
                result["mu"], result["theta"]
            )[0]  # [num_nodes_total]

            # NaN tripwire on outputs
            assert not torch.isnan(mu).any(), f"t={t}: NaN in mu"
            assert not torch.isnan(std_dev).any(), f"t={t}: NaN in std_dev"

            # Store per-node prediction & uncertainty
            for node_id in range(num_nodes_total):
                timeseries_data[node_id].append({
                    "t": t,
                    "prediction": round(float(mu[node_id]), 4),
                    "uncertainty": round(float(std_dev[node_id]), 4),
                })

            # -------- Imputation analytics (length-96 arrays per node) --------
            # imputed_features: [1, num_nodes_total, seq_len, time_series_dim]
            imputed_features: torch.Tensor = result["imputed_features"]
            assert imputed_features.shape == (
                1, num_nodes_total, args.seq_len, time_series_dim
            ), (
                f"t={t}: unexpected imputed_features shape "
                f"{tuple(imputed_features.shape)} (expected "
                f"(1, {num_nodes_total}, {args.seq_len}, {time_series_dim}))"
            )
            assert not torch.isnan(imputed_features).any(), \
                f"t={t}: NaN in imputed_features"

            # Take the LAST step of the reconstructed window, traffic channel (0).
            # Inverse-transform from scaled space → raw counts:
            #   x_raw = x_scaled * scale_[0] + mean_[0]
            imputed_last_scaled = imputed_features[0, :, -1, 0]  # [num_nodes_total]
            imputed_last_raw = imputed_last_scaled * traffic_scale + traffic_mean

            # Mask at the last step, traffic channel — boolean per node
            real_mask_last = real_node_mask[:, -1, 0]  # [num_nodes_real]

            # Ground truth at the absolute timestamp = window_idx + seq_len - 1
            # (last step inside the input window). Pull directly from
            # dataset.unscaled_traffic which is already in raw-count space.
            gt_index = window_idx + args.seq_len - 1
            assert 0 <= gt_index < dataset.unscaled_traffic.shape[0], \
                f"t={t}: gt_index={gt_index} out of bounds"
            real_gt = dataset.unscaled_traffic[gt_index]  # numpy [num_nodes_real]

            for node_id in range(num_nodes_real):
                imputed_series[node_id].append(
                    round(float(imputed_last_raw[node_id]), 4)
                )
                # clamp(min=0) on display-only ground truth (matches the dataset's
                # target_forecast clamp; raw counts cannot be negative).
                ground_truth_series[node_id].append(
                    round(max(0.0, float(real_gt[node_id])), 4)
                )
                mask_series[node_id].append(bool(real_mask_last[node_id]))

            # Simulated nodes: every input was NaN → fully imputed by definition.
            # No physical sensor → no ground truth (encode as None / null in JSON).
            for j in range(num_simulated):
                node_id = num_nodes_real + j
                imputed_series[node_id].append(
                    round(float(imputed_last_raw[node_id]), 4)
                )
                ground_truth_series[node_id].append(None)
                mask_series[node_id].append(True)

            # -------- Attention weights --------
            alpha: torch.Tensor = result["attention_weights"]  # [batch*seq_len*E, heads]
            edge_index: torch.Tensor = result["edge_index"]    # [2, E]
            num_edges = edge_index.shape[1]

            # Cache edge_index from first timestep (topology is static — derived
            # from fixed static_features, deterministic across all timesteps)
            if edge_index_cached is None:
                edge_index_cached = edge_index.cpu()
                # Pre-initialise attention accumulator for every edge
                for e in range(num_edges):
                    src = int(edge_index_cached[0, e])
                    tgt = int(edge_index_cached[1, e])
                    edge_attention_data[(src, tgt)] = []

            # Average attention across heads for the last step in the sequence
            per_edge_attn = extract_timestep_attention(alpha, num_edges, args.seq_len)  # [E]
            assert not torch.isnan(per_edge_attn).any(), f"t={t}: NaN in attention weights"

            for e in range(num_edges):
                src = int(edge_index_cached[0, e])
                tgt = int(edge_index_cached[1, e])
                edge_attention_data[(src, tgt)].append(round(float(per_edge_attn[e]), 6))

            if (t + 1) % 10 == 0 or t == num_timesteps - 1:
                logger.info(f"  Timestep {t + 1}/{num_timesteps} complete | edges={num_edges}")

    logger.info("Inference loop complete.")

    # ------------------------------------------------------------------
    # 8. Assemble JSON payload
    # ------------------------------------------------------------------
    logger.info("Assembling JSON payload …")

    nodes_payload: List[Dict] = []
    for meta in nodes_meta:
        node_id = meta["id"]
        nodes_payload.append({
            "id": node_id,
            "location_name": meta["location_name"],
            "lat": meta["lat"],
            "lon": meta["lon"],
            "is_simulated": meta["is_simulated"],
            "timeseries": timeseries_data[node_id],
            "ground_truth_series": ground_truth_series[node_id],
            "imputed_series": imputed_series[node_id],
            "mask_series": mask_series[node_id],
        })

    edges_payload: List[Dict] = []
    for (src, tgt), attn_seq in edge_attention_data.items():
        edges_payload.append({
            "source": src,
            "target": tgt,
            "attention_sequence": attn_seq,
        })

    payload = {
        "metadata": {
            "num_nodes": num_nodes_total,
            "num_real_nodes": num_nodes_real,
            "num_simulated_nodes": num_simulated,
            "timesteps": num_timesteps,
            "seq_len": args.seq_len,
            "veh_class": args.veh_class,
            "dir": args.dir,
            "start_date": args.start_date,
            "end_date": args.end_date,
        },
        "nodes": nodes_payload,
        "edges": edges_payload,
    }

    # ------------------------------------------------------------------
    # 9. Schema validation (fast assertions before writing)
    # ------------------------------------------------------------------
    assert len(payload["nodes"]) == num_nodes_total, "Node count mismatch in payload"
    # Verify simulated nodes are present and flagged
    sim_nodes_found = [n for n in payload["nodes"] if n["is_simulated"]]
    assert len(sim_nodes_found) == num_simulated, \
        f"Expected {num_simulated} simulated nodes, found {len(sim_nodes_found)}"
    # Verify timeseries length
    for node in payload["nodes"]:
        assert len(node["timeseries"]) == num_timesteps, \
            f"Node {node['id']} has {len(node['timeseries'])} timesteps, expected {num_timesteps}"
        assert len(node["ground_truth_series"]) == num_timesteps, \
            f"Node {node['id']} ground_truth_series len={len(node['ground_truth_series'])} != {num_timesteps}"
        assert len(node["imputed_series"]) == num_timesteps, \
            f"Node {node['id']} imputed_series len={len(node['imputed_series'])} != {num_timesteps}"
        assert len(node["mask_series"]) == num_timesteps, \
            f"Node {node['id']} mask_series len={len(node['mask_series'])} != {num_timesteps}"
        if node["is_simulated"]:
            assert all(g is None for g in node["ground_truth_series"]), \
                f"Simulated node {node['id']} must have null ground_truth_series"
            assert all(m is True for m in node["mask_series"]), \
                f"Simulated node {node['id']} must have all-true mask_series"
        else:
            assert all(isinstance(g, (int, float)) for g in node["ground_truth_series"]), \
                f"Real node {node['id']} ground_truth_series must be numeric"
    # Verify edge attention sequence length
    for edge in payload["edges"]:
        assert len(edge["attention_sequence"]) == num_timesteps, \
            f"Edge ({edge['source']},{edge['target']}) has wrong attention_sequence length"

    logger.info(
        f"Schema validation passed | "
        f"nodes={num_nodes_total} | "
        f"edges={len(edges_payload)} | "
        f"timesteps={num_timesteps}"
    )

    # ------------------------------------------------------------------
    # 10. Write output
    # ------------------------------------------------------------------
    os.makedirs(os.path.dirname(OUTPUT_PATH), exist_ok=True)
    with open(OUTPUT_PATH, "w") as fh:
        json.dump(payload, fh, indent=2)

    file_size_mb = os.path.getsize(OUTPUT_PATH) / (1024 ** 2)
    logger.info(f"Payload written to {OUTPUT_PATH}  ({file_size_mb:.2f} MB)")
    logger.info("export_ui_payload.py COMPLETE.")


if __name__ == "__main__":
    main()

class StaticFeatureLoader:
    def __init__(self, cache_path: str = 'data/external/places_cache.json'):
        """
        Initializes the loader with API security and caching.
        Uses Google Places API (New) as legacy APIs are disabled.
        """
        self.api_key = os.environ.get('GOOGLE_PLACES_API_KEY')
        if self.api_key is None:
            raise ValueError("GOOGLE_PLACES_API_KEY not found in environment.")
        
        self.cache_path = cache_path
        self.cache = self._load_cache()
        logger.info(f"Initialized StaticFeatureLoader with cache: {self.cache_path}")

    def _load_cache(self) -> dict:
        if os.path.exists(self.cache_path):
            try:
                with open(self.cache_path, 'r') as f:
                    return json.load(f)
            except Exception as e:
                logger.error(f"Error loading cache: {e}. Starting fresh.")
                return {}
        return {}

    def _save_cache(self):
        os.makedirs(os.path.dirname(self.cache_path), exist_ok=True)
        with open(self.cache_path, 'w') as f:
            json.dump(self.cache, f, indent=2)

    def _fetch_location_data(self, lat: float, lon: float) -> dict:
        """
        Queries Google Places API (New) for location features.
        Implements Offensive Programming: crash on quota or auth failures.
        """
        def get_count(place_type, radius):
            url = "https://places.googleapis.com/v1/places:searchNearby"
            headers = {
                "Content-Type": "application/json",
                "X-Goog-Api-Key": self.api_key,
                "X-Goog-FieldMask": "places.id"
            }
            payload = {
                "includedTypes": [place_type],
                "locationRestriction": {
                    "circle": {
                        "center": {
                            "latitude": lat,
                            "longitude": lon
                        },
                        "radius": float(radius)
                    }
                }
            }
            
            response = requests.post(url, headers=headers, json=payload)
            
            # OFFENSIVE ASSERTION: Check response status code
            if response.status_code == 403 or response.status_code == 429:
                raise RuntimeError(f"CRITICAL: Google Places API Quota/Auth Error: {response.status_code} - {response.text}")
            
            if response.status_code != 200:
                # Handle other errors gracefully but log them
                logger.warning(f"API Error: {response.status_code} - {response.text}")
                return 0
            
            data = response.json()
            # If no results found, the API (New) returns an empty dictionary {}
            places = data.get('places', [])
            return min(len(places), 50)

        # 1. Commercial Density: Query for type=store within 500m
        comm_count = get_count('store', 500)
        
        # 2. School Zone: Query for type=school within 250m. Return True if count > 0.
        school_count = get_count('school', 250)
        is_school_zone = school_count > 0
        
        # 3. Highway Proximity: Fallback strategy using transit_station within 500m.
        transit_count = get_count('transit_station', 500)
        
        return {
            'commercial_density': int(comm_count),
            'is_school_zone': bool(is_school_zone),
            'highway_proximity': int(transit_count)
        }

    def join_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Enriches traffic sensor data with live Google Places features using a caching layer.
        """
        logger.info("Starting join_features with live Google Places API logic.")
        
        # Load unique location names and their coordinates from traffic_sensors.json
        sensors_path = 'data/traffic_sensors.json'
        try:
            with open(sensors_path, 'r') as f:
                sensors_data = json.load(f)
        except FileNotFoundError:

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.utils import dense_to_sparse
from typing import Tuple

class DynamicGraphLearner(nn.Module):
    """
    DynamicGraphLearner: Infers graph topology from static node features.
    
    Architecture:
    1. Linear projection to latent space.
    2. Pairwise dot-product similarity to form adjacency matrix.
    3. ReLU and tunable sparsity thresholding.
    4. Sparse conversion to (edge_index, edge_weight).
    """
    def __init__(self, static_feat_dim: int, embedding_dim: int = 32, sparsity_threshold: float = 0.5):
        super(DynamicGraphLearner, self).__init__()
        # Ensure random seeds are handled globally or at the top of the script
        
        self.static_feat_dim = static_feat_dim
        self.embedding_dim = embedding_dim
        
        # Parameterized projection layer
        self.lin = nn.Linear(static_feat_dim, embedding_dim)
        
        # Tunable sparsity threshold (can be a learned parameter if needed, but here a buffer/float)
        self.register_buffer('sparsity_threshold', torch.tensor(sparsity_threshold))

    def forward(self, static_features: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Forward pass:
        Args:
            static_features: [num_nodes, static_feat_dim]
        Returns:
            edge_index: [2, E]
            edge_weight: [E]
        """
        assert static_features.dim() == 2, f"Expected static_features shape [num_nodes, static_feat_dim], got {static_features.shape}"
        assert static_features.shape[1] == self.static_feat_dim, f"Feature dimension mismatch: {static_features.shape[1]} != {self.static_feat_dim}"

        num_nodes = static_features.shape[0]

        # 1. Project to embedding space
        # [num_nodes, embedding_dim]
        embeddings = self.lin(static_features)

        # 2. Pairwise dot-product similarity
        # [num_nodes, num_nodes]
        adj = torch.matmul(embeddings, embeddings.t())

        # 3. Apply ReLU to ensure non-negative weights
        adj = F.relu(adj)

        # 4. Sparsity: Subtract threshold and apply ReLU
        # This drops connections with weights <= sparsity_threshold
        adj = adj - self.sparsity_threshold
        adj = F.relu(adj)

        # 5. Convert to sparse format
        edge_index, edge_weight = dense_to_sparse(adj)

        return edge_index, edge_weight

def setup_logger(experiment_name: str) -> logging.Logger:
    """
    Sets up a logger that outputs to both the console and a file in the logs/ directory.
    Crucially, overrides sys.excepthook to log unhandled exceptions and failed assertions
    before the script crashes.
    """
    # Create logs directory if it doesn't exist
    log_dir = os.path.join(os.path.dirname(os.path.dirname(__file__)), "logs")
    os.makedirs(log_dir, exist_ok=True)
    
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = os.path.join(log_dir, f"{experiment_name}_{timestamp}.log")
    
    logger = logging.getLogger() # Root logger
    logger.setLevel(logging.INFO)
    
    # Remove any existing handlers to avoid duplicates
    if logger.hasHandlers():
        logger.handlers.clear()
        
    formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
    
    # Console Handler
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setFormatter(formatter)
    logger.addHandler(console_handler)
    
    # File Handler
    file_handler = logging.FileHandler(log_file)
    file_handler.setFormatter(formatter)
    logger.addHandler(file_handler)
    
    logger.info(f"Logger initialized. Writing to {log_file}")
    
    # CRITICAL: Override sys.excepthook for offensive programming crash-logging
    def handle_exception(exc_type, exc_value, exc_traceback):
        if issubclass(exc_type, KeyboardInterrupt):
            # Allow Ctrl+C to work normally without logging as an error
            sys.__excepthook__(exc_type, exc_value, exc_traceback)
            return

        logger.critical("Uncaught exception or assertion failure!", exc_info=(exc_type, exc_value, exc_traceback))
        
        # Also print to standard error for immediate terminal visibility
        traceback.print_exception(exc_type, exc_value, exc_traceback, file=sys.stderr)

    sys.excepthook = handle_exception
    
    return logger

import torch
import numpy as np
from typing import Dict, Union

def calculate_metrics(
    target_forecast: torch.Tensor,
    mu: torch.Tensor,
    pi: torch.Tensor,
    imputed_features: torch.Tensor,
    target_impute: torch.Tensor,
    node_mask: torch.Tensor
) -> Dict[str, Union[float, int]]:
    """
    Calculates human-readable metrics for the ResilientIoTPipeline.

    Args:
        target_forecast: [batch_size, num_nodes] Ground truth future counts.
        mu: [batch_size, num_nodes] Predicted ZINB mean.
        pi: [batch_size, num_nodes] Predicted zero-inflation probability.
        imputed_features: [batch_size, num_nodes, seq_len, time_series_dim] Reconstructed features.
        target_impute: [batch_size, num_nodes, seq_len, time_series_dim] Ground truth historical features.
        node_mask: [batch_size, num_nodes, seq_len, time_series_dim] Mask where NaNs were artificially applied.

    Returns:
        Dict with keys: rmse (float), mae (float), impute_mse (float),
        zero_true_count (int), zero_correct_count (int).
    """
    # 1. RMSE and MAE (Forecasting)
    # mu is predicted mean count
    mse_forecast = torch.mean((target_forecast - mu)**2)
    rmse = torch.sqrt(mse_forecast).item()
    mae = torch.mean(torch.abs(target_forecast - mu)).item()

    # 2. Zero-Accuracy counts (aggregated by caller to avoid batch-averaging bias)
    # zero_true_count: number of positions where target_forecast == 0
    # zero_correct_count: among those, how many have pi > 0.5
    zero_indices = (target_forecast == 0)
    zero_true_count: int = int(zero_indices.sum().item())
    if zero_true_count > 0:
        zero_correct_count: int = int((pi[zero_indices] > 0.5).sum().item())
    else:
        zero_correct_count = 0

    # 3. Imputation MSE
    # Calculate MSE strictly where node_mask is True (the artificial NaNs)
    if node_mask.any():
        # Ensure node_mask matches the shape of imputed_features/target_impute
        # Based on src/train.py mock data, node_mask has the same shape as dynamic_features [B, N, T, D]
        diff_sq = (imputed_features - target_impute)**2
        impute_mse = torch.mean(diff_sq[node_mask]).item()
    else:
        impute_mse = 0.0

    return {
        "rmse": rmse,
        "mae": mae,
        "zero_true_count": zero_true_count,
        "zero_correct_count": zero_correct_count,
        "impute_mse": impute_mse
    }

from torch.utils.data import DataLoader

class ResilientIoTPipeline(nn.Module):
    """
    ResilientIoTPipeline: End-to-end spatiotemporal model for IoT sensor networks.
    Integrates Topology Inference, Spatiotemporal Encoding, and Multi-Task Decoders.
    """
    def __init__(self,
                 num_nodes: int,
                 static_feat_dim: int,
                 time_series_dim: int,
                 seq_len: int,
                 embedding_dim: int = 32,
                 hidden_dim: int = 64,
                 sparsity_threshold: float = 0.5):
        super(ResilientIoTPipeline, self).__init__()

        # 1. Topology Inference
        self.graph_learner = DynamicGraphLearner(
            static_feat_dim=static_feat_dim,
            embedding_dim=embedding_dim,
            sparsity_threshold=sparsity_threshold
        )
        logger.info(f"Initialized DynamicGraphLearner with static_feat_dim={static_feat_dim}, embedding_dim={embedding_dim}, sparsity_threshold={sparsity_threshold}, total_params={sum(p.numel() for p in self.graph_learner.parameters())}")

        # 2. Spatiotemporal Feature Extraction
        self.encoder = MaskedSpatiotemporalEncoder(
            num_nodes=num_nodes,
            seq_len=seq_len,
            time_series_dim=time_series_dim,
            hidden_dim=hidden_dim
        )
        logger.info(f"Initialized MaskedSpatiotemporalEncoder with num_nodes={num_nodes}, seq_len={seq_len}, time_series_dim={time_series_dim}, hidden_dim={hidden_dim}, total_params={sum(p.numel() for p in self.encoder.parameters())}")

        # 3. Multi-Task Decoders
        self.decoders = DecoupledDecoders(
            hidden_dim=hidden_dim,
            time_series_dim=time_series_dim
        )
        logger.info(f"Initialized DecoupledDecoders with hidden_dim={hidden_dim}, time_series_dim={time_series_dim}, total_params={sum(p.numel() for p in self.decoders.parameters())}")

    def forward(
        self,
        batch: dict,
        return_analysis: bool = False,
    ) -> Union[Tuple[torch.Tensor, ...], Dict[str, torch.Tensor]]:
        """
        Args:
            batch (dict): Expected keys:
                - static_features: [num_nodes, static_feat_dim]
                - dynamic_features: [batch_size, num_nodes, seq_len, time_series_dim]
                - target_forecast: [batch_size, num_nodes]  (not required in analysis mode)
                - target_impute: [batch_size, num_nodes, seq_len, time_series_dim]  (not required in analysis mode)
                - node_mask: [batch_size, num_nodes, seq_len, time_series_dim]  (not required in analysis mode)
            return_analysis: If True, complete the full forward pass through the decoders
                but bypass loss calculation. Returns a comprehensive dict with graph
                structure, attention weights, and ZINB distribution parameters for
                post-hoc interpretability and UI payload generation.
        Returns:
            Normal mode: (total_loss, loss_impute, loss_forecast, imputed_features, mu, theta, pi)
            Analysis mode: {'edge_index', 'edge_weight', 'attention_weights',
                            'imputed_features', 'mu', 'theta', 'pi'}
        """
        static_features = batch['static_features']
        dynamic_features = batch['dynamic_features']

        # Defensive Data Handling
        # Replace NaNs (injected by our Dataset masking or simulated nodes) with 0.0
        dynamic_features_clean = torch.nan_to_num(dynamic_features, nan=0.0)

        # 1. Graph Learner
        edge_index, edge_weight = self.graph_learner(static_features)

        # 2. Encoder — request attention weights when in analysis mode
        if return_analysis:
            latent_embeddings, alpha = self.encoder(
                dynamic_features_clean, edge_index, edge_weight,
                return_attention_weights=True,
            )

            # 3. Decoders (complete the full pass to get ZINB parameters)
            imputed_features, mu, theta, pi = self.decoders(latent_embeddings)

            return {
                'edge_index': edge_index,
                'edge_weight': edge_weight,
                'attention_weights': alpha,
                'imputed_features': imputed_features,
                'mu': mu,
                'theta': theta,
                'pi': pi,
            }

        # Normal training mode — need loss targets
        target_forecast = batch['target_forecast']
        target_impute = batch['target_impute']

        latent_embeddings = self.encoder(dynamic_features_clean, edge_index, edge_weight)

        # 3. Decoders
        imputed_features, mu, theta, pi = self.decoders(latent_embeddings)

        # 4. Compute Joint Loss
        loss, loss_impute, loss_forecast = compute_loss(
            imputed_features=imputed_features,
            target_impute=target_impute,
            mu=mu,
            theta=theta,
            pi=pi,
            target_forecast=target_forecast
        )

        # CRITICAL SAFEGUARD
        assert not torch.isnan(loss).any(), "CRITICAL FAILURE: Pipeline total_loss is NaN."

        return loss, loss_impute, loss_forecast, imputed_features, mu, theta, pi

import logging
import numpy as np
import pandas as pd
from typing import Dict, List

# Standard random seed initialization
np.random.seed(42)

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
logger = logging.getLogger(__name__)


class SensorMappingError(Exception):
    """Custom exception raised when spatial join fails to map a traffic sensor to a weather sensor."""
    pass


class PreprocessingPipeline:
    def __init__(self, frequency: str = '15min'):
        self.frequency = frequency
        logger.info(f"Initialized PreprocessingPipeline with frequency: {self.frequency}")

    def resample_traffic(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Resamples the irregular traffic data into a continuous frequency grid.
        Missing timestamps will reappear as explicit NaN rows.
        """
        logger.info(f"Starting resample_traffic. Input shape: {df.shape}")

        # Assertion: Input dataframe is not empty
        assert not df.empty, "Input dataframe is empty."
        
        # Assertion: Contains required columns
        required_cols = ['location', 'category', 'veh_class', 'dir', 'dt', 'value']
        for col in required_cols:
            assert col in df.columns, f"Missing required column: {col}"

        if not pd.api.types.is_datetime64_any_dtype(df['dt']):
            df['dt'] = pd.to_datetime(df['dt'])

        # Handle physical impossibilities (negative values) before resampling
        # Tripwire: Ensure no silent suppression, explicitly convert anomalous negatives to NaN
        df.loc[df['value'] < 0, 'value'] = np.nan

        # Generate the global target grid
        min_dt = df['dt'].min().floor(self.frequency)
        max_dt = df['dt'].max().ceil(self.frequency)
        expected_index = pd.date_range(start=min_dt, end=max_dt, freq=self.frequency, name='dt')

        # Group and resample
        groups = ['location', 'category', 'veh_class', 'dir']
        
        # We'll build the continuous grid for each group explicitly
        resampled_list = []
        unique_groups = df[groups].drop_duplicates().dropna(subset=groups)
        
        for _, row in unique_groups.iterrows():
            logger.info(f"DEBUG: Processing group: {row.to_dict()}")
            group_mask = True
            for col in groups:
                group_mask &= (df[col] == row[col])
            
            group_df = df[group_mask].set_index('dt')
            # Resample and reindex to global grid
            group_resampled = group_df['value'].resample(self.frequency).sum(min_count=1).reindex(expected_index)
            
            # Reconstruct the group columns
            temp_df = group_resampled.reset_index()
            # If the index was named 'dt', it appears as 'dt'. If unnamed, it appears as 'index'.
            if 'index' in temp_df.columns:
                temp_df = temp_df.rename(columns={'index': 'dt'})
            
            # Ensure the value column is correctly named
            potential_value_cols = [c for c in temp_df.columns if c != 'dt']
            if potential_value_cols:
                temp_df = temp_df.rename(columns={potential_value_cols[0]: 'value'})
            for col in groups:
                temp_df[col] = row[col]
            
            resampled_list.append(temp_df)
        
        final_df = pd.concat(resampled_list, ignore_index=True)

        # Grid Validation Tripwire
        observed_groups = df[groups].drop_duplicates()
        expected_total_rows = len(observed_groups) * len(expected_index)
        assert len(final_df) == expected_total_rows, (
            f"Grid validation failed: Expected {expected_total_rows} rows, "
            f"but got {len(final_df)}."
        )

        logger.info(f"Resampling complete. Output shape: {final_df.shape}")
        return final_df

    def impute_missingness(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Missingness-Aware Imputation Strategy.
        Prioritizes 'Missing Zero' imputation and leaves true gaps as NaN.
        """
        logger.info(f"Starting impute_missingness. Input shape: {df.shape}")
        assert not df.empty, "Dataframe is empty before imputation."
        assert 'dt' in df.columns and 'value' in df.columns, "Missing 'dt' or 'value' columns."
        
        # Priority 1: Structural Missingness (Zero-Priority)
        # Using a simple contextual heuristic: If it's late night (00:00 to 04:59), assume missing means 0 traffic.
        hour = df['dt'].dt.hour
        is_night = (hour >= 0) & (hour < 5)
        
        structural_zero_mask = df['value'].isna() & is_night
        df.loc[structural_zero_mask, 'value'] = 0.0
        
        # Priority 2: True Gaps
        # All other NaN values remain as NaN to maintain missingness awareness.
        # Explicitly DO NOT use .fillna(method='ffill') or .dropna()
        
        logger.info(f"Imputation complete. Remaining explicit NaNs: {df['value'].isna().sum()}")
        return df

    def spatial_join(self, traffic_df: pd.DataFrame, traffic_sensors: List[Dict], weather_sensors: List[Dict]) -> pd.DataFrame:
        """
        Maps each traffic sensor to the nearest weather sensor using spatial coordinates.
        """
        logger.info("Starting spatial_join.")
        assert not traffic_df.empty, "Traffic dataframe is empty."
        assert len(traffic_sensors) > 0, "No traffic sensors provided."
        assert len(weather_sensors) > 0, "No weather sensors provided."

        # Spatial Edge Case: N=1 weather sensors
        if len(weather_sensors) == 1:
            logger.info("Only 1 weather sensor found. Bypassing distance matrix calculation.")
            weather_sensor_name = weather_sensors[0].get('Sensor_Name')
            assert weather_sensor_name is not None, "Weather sensor missing 'Sensor_Name'."
            nearest_mapping = {ts['location']: weather_sensor_name for ts in traffic_sensors}
        else:
            logger.info(f"Calculating distance matrix for {len(weather_sensors)} weather sensors.")
            nearest_mapping = {}
            for ts in traffic_sensors:
                assert 'lat' in ts and 'lon' in ts, f"Traffic sensor missing lat/lon: {ts}"
                
                min_dist = float('inf')
                best_ws = None
                
                for ws in weather_sensors:
                    assert 'Sensor_Centroid_Latitude' in ws and 'Sensor_Centroid_Longitude' in ws, (
                        f"Weather sensor missing coordinates: {ws}"
                    )
                    
                    dy = ts['lat'] - ws['Sensor_Centroid_Latitude']
                    dx = ts['lon'] - ws['Sensor_Centroid_Longitude']
                    dist = dy**2 + dx**2  # Simplified squared distance (Euclidean approximation of Haversine)
                    
                    if dist < min_dist:
                        min_dist = dist
                        best_ws = ws.get('Sensor_Name')
                
                if best_ws is None:
                    raise SensorMappingError(f"Failed to map traffic sensor {ts['location']} to any weather sensor.")
                
                nearest_mapping[ts['location']] = best_ws

        traffic_df['nearest_weather_sensor'] = traffic_df['location'].map(nearest_mapping)

        # No Silent Drops: Crash if spatial join fails for any location
        if traffic_df['nearest_weather_sensor'].isna().any():
            unmapped = traffic_df[traffic_df['nearest_weather_sensor'].isna()]['location'].unique()
            raise SensorMappingError(f"Spatial join failed to find sensor mapping for locations: {unmapped}")

        logger.info(f"Spatial join complete. Output shape: {traffic_df.shape}")
        return traffic_df

    def enrich_static_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Defines the schema and integrates external static metadata features per sensor location.
        """
        logger.info("Starting enrich_static_features.")
        assert 'location' in df.columns, "Location column missing for static features."

        unique_locs = df['location'].unique()
        
        # Schema Definition for Google Places API integration
        mock_metadata = pd.DataFrame({
            'location': unique_locs,
            'highway_proximity': np.nan,  # Float: Distance to nearest major highway

            'school_zone': False          # Boolean: Inside/adjacent to a school zone
        })

        # Assert features were successfully attached
        for col in ['highway_proximity', 'commercial_density', 'school_zone']:
            assert col in df.columns, f"Failed to integrate static feature: {col}"
            
        logger.info(f"Static feature enrichment complete. Output shape: {df.shape}")
        return df

def prepare_weather_data(weather_path: str, frequency: str = '15min') -> pd.DataFrame:
    """Loads, pivots, and resamples weather data to the target frequency."""
    logger.info("Loading weather data...")
    df = pd.read_parquet(weather_path)
    
    # Drop units as per EDA
    if 'units' in df.columns:
        df = df.drop(columns=['units'])
        
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    
    logger.info("Pivoting weather data...")
    pivoted = df.pivot_table(
        index=['sensor_name', 'timestamp'],
        columns='variable',
        values='value',
        aggfunc='mean'
    ).reset_index()
    
    logger.info("Resampling weather data to %s...", frequency)
    # Resample weather data to ensure it aligns with the 15min grid
    # We will set index to timestamp, group by sensor_name, and resample
    def resample_weather(g):
        return g.set_index('timestamp').resample(frequency).mean()
        
    # Apply resampling
    resampled_weather = pivoted.groupby('sensor_name').apply(resample_weather)
    resampled_weather = resampled_weather.reset_index()
    
    logger.info(f"Weather data prepared. Shape: {resampled_weather.shape}")
    return resampled_weather

def process_full_dataset():
    traffic_path = 'data/traffic_20230108_20260108.parquet'
    weather_path = 'data/weather_20230108_20260108.parquet'
    output_dir = 'data/processed'
    output_file = os.path.join(output_dir, 'master_dataset_15T.parquet')
    
    os.makedirs(output_dir, exist_ok=True)
    
    with open('data/traffic_sensors.json', 'r') as f:
        traffic_sensors = json.load(f)
    with open('data/weather_sensors.json', 'r') as f:
        weather_sensors = json.load(f)

    # Prepare external datasets
    weather_df = prepare_weather_data(weather_path, frequency='15min')
    feature_loader = StaticFeatureLoader()
    pipeline = PreprocessingPipeline(frequency='15min')
    
    logger.info("Discovering unique locations in traffic data...")
    # Load just locations to get unique ones
    locs_df = pd.read_parquet(traffic_path, columns=['location'])
    unique_locations = locs_df['location'].unique()
    del locs_df
    gc.collect()
    
    logger.info(f"Found {len(unique_locations)} unique locations to process. Starting chunked processing...")
    
    # Process sequentially by location to be safe with RAM
    first_chunk = True
    processed_rows = 0
    
    # Read full traffic data into memory (21M rows, ~6 cols, fits in RAM easily, we just chunk the processing)
    # Actually, 21M rows is a bit large, let's load it and group by location.
    # To be extremely memory safe, we could read filters with pyarrow, but loading once is faster if it fits.
    # Let's try loading it once and chunking the DataFrame.
    full_traffic = pd.read_parquet(traffic_path)
    
    import pyarrow as pa
    import pyarrow.parquet as pq
    
    writer = None
    
    for loc in unique_locations:
        loc_df = full_traffic[full_traffic['location'] == loc].copy()
        
        # 1. Resample
        resampled_df = pipeline.resample_traffic(loc_df)
        
        # 2. Impute
        imputed_df = pipeline.impute_missingness(resampled_df)
        
        # 3. Spatial Join
        joined_df = pipeline.spatial_join(imputed_df, traffic_sensors, weather_sensors)
        
        # 4. Static Feature Join
        enriched_df = feature_loader.join_features(joined_df)
        
        # 5. Weather Time Series Join
        # Merge on nearest_weather_sensor and dt
        final_chunk = enriched_df.merge(
            weather_df,
            left_on=['nearest_weather_sensor', 'dt'],
            right_on=['sensor_name', 'timestamp'],
            how='left'
        )
        # Drop redundant columns from weather
        if 'sensor_name' in final_chunk.columns:
            final_chunk = final_chunk.drop(columns=['sensor_name'])
        if 'timestamp' in final_chunk.columns:
            final_chunk = final_chunk.drop(columns=['timestamp'])
            
        # Write to parquet file using pyarrow iterative writer
        table = pa.Table.from_pandas(final_chunk)
        if writer is None:
            writer = pq.ParquetWriter(output_file, table.schema)
        writer.write_table(table)
            
        processed_rows += len(final_chunk)
        logger.info(f"Processed location {loc}. Total accumulated rows: {processed_rows}")
        
        # Free memory
        del loc_df, resampled_df, imputed_df, joined_df, enriched_df, final_chunk, table
        gc.collect()

    if writer is not None:
        writer.close()

    logger.info(f"Full scale processing complete. Saved to {output_file}")
    logger.info(f"Total Rows: {processed_rows}")

if __name__ == "__main__":
    process_full_dataset()

def create_mock_dataloader(
    batch_size: int,
    num_nodes: int,
    seq_len: int,
    time_series_dim: int,
    static_feat_dim: int,
    dataset_size: int,
):
    """
    Creates a mock DataLoader yielding batches that match the pipeline's
    expected dimensional structure.
    """
    class MockPipelineDataset(torch.utils.data.Dataset):
        def __init__(self, size: int):
            self.size = size
            self.num_nodes = num_nodes
            self.static_feat_dim = static_feat_dim
            self.time_series_dim = time_series_dim

        def __len__(self) -> int:
            return self.size

        def __getitem__(self, idx: int) -> dict:
            dyn = torch.randn(num_nodes, seq_len, time_series_dim)
            mask = torch.rand_like(dyn) < 0.15
            dyn_masked = dyn.clone()
            dyn_masked[mask] = float("nan")
            return {
                "static_features": torch.randn(num_nodes, static_feat_dim),
                "dynamic_features": dyn_masked,
                "target_impute": dyn.clone(),
                "target_forecast": torch.randint(0, 50, (num_nodes,)).float(),
                "node_mask": mask,
            }

    dataset = MockPipelineDataset(size=dataset_size)

    def custom_collate(batch_list):
        return {
            "static_features": batch_list[0]["static_features"],
            "dynamic_features": torch.stack([b["dynamic_features"] for b in batch_list]),
            "target_impute": torch.stack([b["target_impute"] for b in batch_list]),
            "target_forecast": torch.stack([b["target_forecast"] for b in batch_list]),
            "node_mask": torch.stack([b["node_mask"] for b in batch_list]),
        }

    return DataLoader(dataset, batch_size=batch_size, collate_fn=custom_collate), dataset


def run_training(config: dict, init_wandb: bool = True, use_mock_data: bool = False) -> float:
    """
    Core execution logic for a single training run.
    Accepts a fully-specified config dictionary (see configs/train.yaml).
    Returns the final validation loss.
    """
    logger = logging.getLogger(__name__)

    # Reproducibility
    torch.manual_seed(42)
    np.random.seed(42)

    # Device configuration
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

    # ------------------------------------------------------------------ #

    model_cfg = config["model"]

            seq_len=data_cfg["seq_len"],
            time_series_dim=model_cfg["time_series_dim"],
            static_feat_dim=model_cfg["static_feat_dim"],

            batch_size=train_cfg["batch_size"],
            num_nodes=model_cfg["num_nodes"],
            seq_len=data_cfg["seq_len"],
            time_series_dim=model_cfg["time_series_dim"],
            static_feat_dim=model_cfg["static_feat_dim"],
            dataset_size=8,
        )

        logger.info(f"Loading RealIoTDataset from {data_cfg['start_date']} to {data_cfg['end_date']}")

                data_cfg["end_date"],

                target_veh_class=data_cfg["target_veh_class"],
                target_dir=data_cfg["target_dir"],
            )

            val_size = len(full_dataset) - train_size

            if train_size == 0 or val_size == 0:
                raise ValueError(
                    "Not enough data to split into train and val. Try a wider date range."
                )

            train_dataset, val_dataset = torch.utils.data.random_split(
                full_dataset, [train_size, val_size]
            )

            # model initializer below can read them uniformly.
            train_dataset.num_nodes = full_dataset.num_nodes

        except Exception as e:

            raise

        f"embedding_dim={model_cfg['embedding_dim']}, "
        f"hidden_dim={model_cfg['hidden_dim']}"

    epochs = train_cfg["epochs"]
    for epoch in range(epochs):
        model.train()

        epoch_loss_forecast = 0.0
        epoch_loss_impute = 0.0

        for batch in train_loader:
            batch = {k: v.to(device) if torch.is_tensor(v) else v for k, v in batch.items()}

            optimizer.zero_grad()
            loss, loss_impute, loss_forecast, _, _, _, _ = model(batch)
            loss.backward()

            # CRITICAL SAFEGUARD: Gradient Clipping (from BACKEND_ARCHITECTURE.md)
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

            optimizer.step()

            epoch_loss_total += loss.item()
            epoch_loss_impute += loss_impute.item()
            epoch_loss_forecast += loss_forecast.item()

        avg_train_loss = epoch_loss_total / len(train_loader)
        avg_train_impute = epoch_loss_impute / len(train_loader)
        avg_train_forecast = epoch_loss_forecast / len(train_loader)

        # Validation Loop
        model.eval()
        val_loss_total = 0.0
        val_metrics_accum = {"rmse": 0.0, "mae": 0.0, "impute_mse": 0.0}
        zero_true_total = 0
        zero_correct_total = 0

        with torch.no_grad():
            for batch in val_loader:
                batch = {k: v.to(device) if torch.is_tensor(v) else v for k, v in batch.items()}
                loss, _, _, imputed_features, mu, _, pi = model(batch)
                val_loss_total += loss.item()

                batch_metrics = calculate_metrics(
                    target_forecast=batch["target_forecast"],
                    mu=mu,
                    pi=pi,
                    imputed_features=imputed_features,
                    target_impute=batch["target_impute"],
                    node_mask=batch["node_mask"],
                )
                for k in val_metrics_accum:
                    val_metrics_accum[k] += batch_metrics[k]
                zero_true_total += batch_metrics["zero_true_count"]
                zero_correct_total += batch_metrics["zero_correct_count"]

        avg_val_loss = val_loss_total / len(val_loader)
        val_rmse = val_metrics_accum["rmse"] / len(val_loader)
        val_mae = val_metrics_accum["mae"] / len(val_loader)
        val_zero_acc = zero_correct_total / zero_true_total if zero_true_total > 0 else 0.0
        val_impute_mse = val_metrics_accum["impute_mse"] / len(val_loader)

        # Offensive Assertion for Divergence
        if torch.isnan(torch.tensor(avg_val_loss)):
            raise DivergenceError("Validation loss is NaN! The Burn Test Failed.")

        logger.info(
            f"Epoch {epoch+1}/{epochs} - "
            f"Train Loss: {avg_train_loss:.4f} | "
            f"Val Loss: {avg_val_loss:.4f} "
            f"(RMSE: {val_rmse:.2f}, MAE: {val_mae:.2f}, "
            f"ZeroAcc: {val_zero_acc:.4f} [{zero_correct_total}/{zero_true_total}], "
            f"ImputeMSE: {val_impute_mse:.4f})"
        )

        # Checkpointing
        if avg_val_loss < best_val_loss:
            best_val_loss = avg_val_loss
            checkpoint_path = "models/best_pipeline.pt"
            torch.save(model.state_dict(), checkpoint_path)
            logger.info(
                f"New best model saved to {checkpoint_path} with val_loss: {best_val_loss:.4f}"
            )

        # W&B Logging
        if init_wandb or (wandb.run is not None):
            wandb.log(
                {
                    "train_loss_total": avg_train_loss,
                    "train_loss_impute": avg_train_impute,
                    "train_loss_forecast": avg_train_forecast,
                    "val_loss_total": avg_val_loss,
                    "val_rmse": val_rmse,
                    "val_mae": val_mae,
                    "val_zero_acc": val_zero_acc,
                    "val_zero_true_count": zero_true_total,
                    "val_zero_correct_count": zero_correct_total,
                    "val_impute_mse": val_impute_mse,
                    "epoch": epoch + 1,
                }
            )

    logger.info("Training complete.")
    if init_wandb:
        wandb.finish()

    return avg_val_loss


def main():

    os.path.dirname(os.path.dirname(__file__)), "configs", "train.yaml"

# Mapping from sweep.yaml parameter names to their nested location in train.yaml
_PARAM_PATH: dict[str, tuple[str, str]] = {
    "lr":         ("training", "lr"),
    "w_forecast": ("loss",     "w_forecast"),
    "w_impute":   ("loss",     "w_impute"),
}


def make_objective(base_config: dict, use_mock_data: bool):
    """
    Factory that returns an Optuna objective bound to a deep-copy of
    base_config so each trial starts from the same YAML defaults and Optuna
    suggestions overwrite only the designated keys.
    """
    def objective(trial):
        """
        Optuna objective function for hyperparameter tuning.
        Dynamically generates suggestions based on configs/sweep.yaml and
        merges them into a fresh copy of the base config dict.
        """
        config = copy.deepcopy(base_config)

        for param_name, param_config in SWEEP_CONFIG.get("parameters", {}).items():
            dist = param_config.get("distribution")

            if dist == "log_uniform_values":
                val = trial.suggest_float(
                    param_name,
                    param_config["min"],
                    param_config["max"],
                    log=True,
                )
            elif dist == "uniform":
                val = trial.suggest_float(
                    param_name,
                    param_config["min"],
                    param_config["max"],
                )
            else:
                raise ValueError(f"Unsupported distribution: {dist} for parameter {param_name}")

            section, key = _PARAM_PATH[param_name]
            config[section][key] = val

        # Execute training loop.
        # init_wandb=False prevents train.py from spawning a separate W&B run;
        # the WeightsAndBiasesCallback manages the run at the study level.
        return run_training(config=config, init_wandb=False, use_mock_data=use_mock_data)

    return objective

from graph_learner import DynamicGraphLearner

def test_dynamic_graph_learner():
    torch.manual_seed(42)
    import numpy as np
    np.random.seed(42)

    num_nodes = 50
    static_feat_dim = 10
    embedding_dim = 16
    sparsity_threshold = 0.5
    
    model = DynamicGraphLearner(
        static_feat_dim=static_feat_dim, 
        embedding_dim=embedding_dim, 
        sparsity_threshold=sparsity_threshold
    )

    static_features = torch.randn(num_nodes, static_feat_dim)
    edge_index, edge_weight = model(static_features)

    E = edge_weight.shape[0]
    assert edge_index.shape == (2, E), f"edge_index shape mismatch: {edge_index.shape}"
    assert edge_weight.shape == (E,), f"edge_weight shape mismatch: {edge_weight.shape}"

    assert E > 0, "Graph is completely disconnected (E=0)."
    assert E < (num_nodes * num_nodes), f"Graph is fully connected (E={E}), sparsity threshold not working."

    loss = edge_weight.sum()
    loss.backward()

    for name, param in model.named_parameters():
        assert param.grad is not None, f"Parameter '{name}' has no gradient."

import torch

from metrics import calculate_metrics


def _make_base_tensors(batch_size: int = 2, num_nodes: int = 4, seq_len: int = 3, dim: int = 2):
    """Helper: creates zero-filled tensors matching the expected shapes."""
    target_forecast = torch.zeros(batch_size, num_nodes)
    mu = torch.zeros(batch_size, num_nodes)
    pi = torch.zeros(batch_size, num_nodes)
    imputed_features = torch.zeros(batch_size, num_nodes, seq_len, dim)
    target_impute = torch.zeros(batch_size, num_nodes, seq_len, dim)
    node_mask = torch.zeros(batch_size, num_nodes, seq_len, dim, dtype=torch.bool)
    return target_forecast, mu, pi, imputed_features, target_impute, node_mask


class TestZeroCounts:
    def test_all_zeros_in_target__all_pi_high(self):
        """All targets are 0 and pi > 0.5 everywhere → full counts."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        # All targets are 0 (already), pi set above threshold
        pi = torch.full_like(pi, 0.9)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        expected_true = target_forecast.numel()  # 2 * 4 = 8
        assert metrics["zero_true_count"] == expected_true
        assert metrics["zero_correct_count"] == expected_true

    def test_all_zeros_in_target__all_pi_low(self):
        """All targets are 0 but pi ≤ 0.5 everywhere → zero correct count."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        pi = torch.full_like(pi, 0.3)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        assert metrics["zero_true_count"] == target_forecast.numel()
        assert metrics["zero_correct_count"] == 0

    def test_no_zeros_in_target__returns_zero_counts(self):
        """No target zeros → both counts must be 0 (no fallback 1.0 bias)."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        target_forecast = torch.ones_like(target_forecast) * 5  # all non-zero
        pi = torch.full_like(pi, 0.9)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        assert metrics["zero_true_count"] == 0
        assert metrics["zero_correct_count"] == 0

    def test_mixed_targets__counts_are_exact(self):
        """Only some positions are zero; verify exact integer counts."""
        # Shape [1, 4]: target = [0, 5, 0, 10], pi = [0.9, 0.9, 0.3, 0.9]
        target_forecast = torch.tensor([[0.0, 5.0, 0.0, 10.0]])

        mask = torch.zeros(1, 4, 3, 2, dtype=torch.bool)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        # Zeros at positions 0 and 2; pi[0]=0.9>0.5 ✓, pi[2]=0.3≤0.5 ✗
        assert metrics["zero_true_count"] == 2
        assert metrics["zero_correct_count"] == 1

    def test_return_types_are_int(self):
        """zero_true_count and zero_correct_count must be Python ints."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()

import torch
import pytest
from pipeline import ResilientIoTPipeline
from torch.utils.data import DataLoader

def test_resilient_iot_pipeline():
    torch.manual_seed(42)

    batch_size = 4
    num_nodes = 50
    static_feat_dim = 10
    time_series_dim = 3
    seq_len = 12

    class MockPipelineDataset(torch.utils.data.Dataset):
        def __init__(self, size):
            self.size = size
        def __len__(self):
            return self.size
        def __getitem__(self, idx):
            dyn = torch.randn(num_nodes, seq_len, time_series_dim)
            mask = torch.rand_like(dyn) < 0.15
            dyn_masked = dyn.clone()
            dyn_masked[mask] = float('nan')
            return {
                'static_features': torch.randn(num_nodes, static_feat_dim),
                'dynamic_features': dyn_masked,
                'target_impute': dyn.clone(),
                'target_forecast': torch.randint(0, 50, (num_nodes,)).float(),
                'node_mask': mask
            }
            
    dataset = MockPipelineDataset(size=8)
    
    def custom_collate(batch_list):
        return {
            'static_features': batch_list[0]['static_features'],
            'dynamic_features': torch.stack([b['dynamic_features'] for b in batch_list]),
            'target_impute': torch.stack([b['target_impute'] for b in batch_list]),
            'target_forecast': torch.stack([b['target_forecast'] for b in batch_list]),
            'node_mask': torch.stack([b['node_mask'] for b in batch_list])
        }

    dataloader = DataLoader(dataset, batch_size=batch_size, collate_fn=custom_collate)

    model = ResilientIoTPipeline(
        num_nodes=num_nodes,
        static_feat_dim=static_feat_dim,
        time_series_dim=time_series_dim,
        seq_len=seq_len
    )
    
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

    for batch in dataloader:
        optimizer.zero_grad()
        loss, _, _, _, _, _, _ = model(batch)
        assert not torch.isnan(loss).any()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()
