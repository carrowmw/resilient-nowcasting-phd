# ML Agent Workspace

## Build Instructions

To build the agent workspace container on your local machine, run the following command in the terminal:

```Bash
docker compose build agent-workspace
```

This will build the container that you will use for development on your Mac.

```Bash
docker compose build cpu-runner
```

When you are ready to execute your training script on the GPU server, you will need to build the CUDA image. Run the following command on the server:

```Bash
docker compose build gpu-runner
```

## Execution Instructions

### On Mac (Development):

You will boot the interactive terminal exactly as you have been doing to let the agent code:

```Bash
docker compose run --rm agent-workspace bash
```

### On the GPU Server (Execution):

Once you have pushed your main branch to GitHub and pulled it down to the server, you will run the GPU container to execute the W&B training script:

```Bash
docker compose run --rm gpu-runner python src/process_all.py
```

```Bash
# This builds the CUDA image and runs your training script
docker compose run --rm gpu-runner python src/train.py --epochs 50 --batch_size 128
```

```Bash
# This maps the GPU, mounts the repo, and runs exactly one month of data
docker compose run --rm gpu-runner python src/train.py \
  --epochs 2 \
  --batch_size 128 \
  --start_date "2023-03-02" \
  --end_date "2023-04-02"
```

## Hyperparameter Tuning (Optuna)

The tuning entry point is `src/tune.py`. It launches an Optuna study and logs trial metrics to Weights & Biases through `WeightsAndBiasesCallback`.

The search space is defined in `configs/sweep.yaml`:

- `lr` (log-uniform)
- `w_forecast` (uniform)
- `w_impute` (uniform)

### Local CPU Smoke Sweep (Mock Data)

Use this first to validate the full tuning loop quickly on your Mac:

```Bash
docker compose run --rm cpu-runner python src/tune.py --use_mock_data
```

If you want to keep runs local-only and avoid syncing to W&B cloud:

```Bash
docker compose run --rm cpu-runner bash -lc 'WANDB_MODE=offline python src/tune.py --use_mock_data'
```

### GPU Server Sweep (Real Data)

Run this on the GPU server after pulling the latest code and setting your `.env`:

```Bash
docker compose run --rm gpu-runner python src/tune.py
```

Recommended explicit run (select your exact data window and stream):

```Bash
docker compose run --rm gpu-runner python src/tune.py \
  --n_trials 2 \
  --epochs 2 \
  --batch_size 4 \
  --start_date 2023-10-01 \
  --end_date 2023-10-04 \
  --veh_class person \
  --dir all
```

### Logs and Outputs

- Sweep logs are written to `logs/optuna_sweep_YYYYMMDD_HHMMSS.log`
- Best parameters and best validation loss are printed at the end of the run

### Tune CLI Options

`src/tune.py` now supports CLI overrides so you do not need to edit source code for most sweep changes:

- `--n_trials`
- `--epochs`
- `--batch_size`
- `--start_date`
- `--end_date`
- `--seq_len`
- `--veh_class`
- `--dir`
- `--use_mock_data`

Show all options:

```Bash
docker compose run --rm cpu-runner python src/tune.py --help
```

### Troubleshooting: Empty Data Window / Filter Errors

If your selected `--start_date`, `--end_date`, `--veh_class`, or `--dir` produces no rows, tuning will fail fast with a clear error explaining which filter removed all rows and which values were available in the loaded data. Adjust the date window or stream arguments and rerun.

# Resilient IoT Spatiotemporal Pipeline

## Objective

Implement an end-to-end, joint spatiotemporal graph neural network in PyTorch and PyTorch Geometric (PyG). The model is designed for an urban IoT sensor network (predicting a configurable target traffic stream, defined by vehicle class and spatial direction, every 15 minutes). It must be self-healing, capable of dynamic graph inference, missing feature imputation, and uncertainty-aware forecasting.

## Core Paradigm

The system abandons the I.I.D. assumption, leveraging Graph Attention Networks (GATs) to pass messages along dynamically learned topological connections, alongside Transformers for temporal sequence modelling.

### 1. Architectural Components

The pipeline (ResilientIoTPipeline) consists of three primary modules sharing a latent space:

#### Dynamic Graph Learner (Topology Inference):

- Takes static node features (e.g., coordinates, sensor types).
- Uses a multi-head GAT (or linear embeddings with pairwise similarity) to learn a dynamic adjacency matrix on the fly.
- Applies a ReLU and a sparsity threshold, converting the dense matrix to PyG's edge_index and edge_weight using dense_to_sparse.

#### Masked Spatiotemporal Encoder (Feature Extraction):

- Takes artificially masked dynamic time-series data and the inferred graph structure.

- Spatial: Uses PyG GATv2Conv layers (independently across time steps) to aggregate neighbourhood features.

Temporal: Flattens the spatial output and passes it through a standard PyTorch TransformerEncoder to capture temporal dependencies.

#### Decoupled Decoders (Multi-Task Learning):

Imputation Decoder: A linear layer applied across the entire sequence to reconstruct the artificially masked historical data (Task: Self-healing).

Uncertainty-Aware Forecasting Decoder: A linear layer taking the final time step's embedding. It outputs three parameters representing a Zero-Inflated Negative Binomial (ZINB) distribution: $\mu$ (mean), $\theta$ (dispersion), and $\pi$ (zero-inflation probability).

### 2. Data Pipeline Specifications

The PyTorch Dataset must yield a dictionary for each batch to handle the complex inputs and masking required for joint training. Expected dictionary keys:

static_features: [num_nodes, static_feat_dim] (Physical sensor attributes).

dynamic_features: [batch_size, num_nodes, seq_len, time_series_dim] (Historical sequences with ~15% artificial NaN masking applied for self-supervised imputation training).

target_forecast: [batch_size, num_nodes] (The ground-truth future target counts).

target_impute: [batch_size, num_nodes, seq_len, time_series_dim] (The unmasked historical sequence to calculate imputation loss).

node_mask: [batch_size, num_nodes] (Boolean mask to ignore genuinely offline sensors during loss calculation).

### 3. Joint Training & Loss Logic

The model must be trained simultaneously on all tasks using a central compute_loss method.

Forecasting Loss (ZINB NLL constraints - CRITICAL):
The ZINB distribution is highly volatile and prone to NaN gradients. The implementation must include these mathematical tripwires:

Apply torch.sigmoid to the $\pi$ raw logit.

Apply F.softplus to the $\mu$ and $\theta$ raw logits.

Tripwire: Immediately add eps = 1e-6 to $\mu$ and $\theta$ to mathematically guarantee they never equal exactly zero.

Use torch.lgamma (log-gamma) for factorial equivalents to prevent overflow.

Clamp the minimum value of any torch.log() operation to eps to avoid log(0).

Calculate the Negative Log-Likelihood (NLL) of target_forecast given $\mu$, $\theta$, $\pi$.

Imputation Loss:

Calculates Mean Squared Error (MSE) between the imputed_features and target_impute strictly on the artificially masked nodes.

Total Loss:

$\mathcal{L}_{total} = (w_{forecast} \times \mathcal{L}_{ZINB\_NLL}) + (w_{impute} \times \mathcal{L}_{impute\_MSE})$

Training Loop Safeguards:

To prevent exploding gradients from the joint task, gradient clipping (torch.nn.utils.clip*grad_norm*(model.parameters(), max_norm=1.0)) is mandatory immediately after loss.backward() and before optimizer.step().

The forward pass must include an assert not torch.isnan(loss).any() check that crashes the script intentionally and prints the min/max of $\mu$, $\theta$, and $\pi$ if triggered.

# Exploratory Data Analysis (EDA) Summary

## 1. Datasets Overview

### Traffic Data (`traffic_20230108_20260108.parquet`)
- **Size:** 21,144,475 records, 6 columns.
- **Columns:** `category` (str), `dir` (str), `dt` (datetime64), `location` (str), `value` (int64), `veh_class` (str).
- **Date Range:** 2023-03-02 to 2026-01-08.
- **Description:** Contains traffic measurements (e.g., flow) at various sensor locations broken down by vehicle class (e.g., 'person', 'car') and direction.

### Weather Data (`weather_20230108_20260108.parquet`)
- **Size:** 2,715,140 records, 13 columns.
- **Columns:** `sensor_name` (str), `variable` (str - e.g., 'Humidity', 'Solar Radiation'), `timestamp` (datetime64), `value` (float64), `units` (object), `flagged` (bool), `location_wkt` (str), `sensor_centroid_latitude` (float64), `sensor_centroid_longitude` (float64), `sensor_height_above_ground` (float64), `ground_height_above_sea_level` (float64), `broker_name` (str), `raw_id` (str).
- **Date Range:** 2023-01-08 to 2025-10-20.

### Sensor Metadata JSONs
- **`traffic_sensors.json`:** Maps string `location` identifiers to numeric `lat` and `lon` coordinates.
- **`weather_sensors.json`:** Maps `Sensor_Name` identifiers to `Location_WKT`, `Sensor_Centroid_Latitude`, `Sensor_Centroid_Longitude`, and elevation details.

---

## 2. Likely Target Variable
The likely target variable for predictive modeling is **`value`** in the **Traffic dataset**. 
Since `Congestion_Level` is not present, `value` corresponds to the quantitative traffic flow/volume or speed metric at a given location and time. The goal of an ML pipeline here would likely be to predict the future traffic `value` using historical traffic patterns and correlated weather phenomena.

---

## 3. Data Quality Summary

### Missing Values
- **Traffic Data:** While the data dictionary may suggest a clean dataset with **0 missing values**, this is because missing data in this table does not appear as explicit `NaN` values. Instead, the time series is **irregular and contains missing timestamps (gaps)**.
    - **Temporal Gaps:** The standard measurement frequency should be **15 minutes**. However, the time series is highly irregular: **~23% of gaps** between consecutive sensor readings are larger than 15 minutes, meaning countless timestamps have simply been dropped from the dataset rather than being recorded as null.
    - **Zero-Count Deletion:** Only 1,964 records (out of 21.1M) have a `value` of 0. This confirms that missing periods and zero-traffic moments were omitted. This irregular structure must be corrected via temporal resampling/re-indexing before sequential modeling.
- **Weather Data:** The **`units`** column is entirely empty (2,715,140 missing values) and should be dropped. All other 12 columns contain **0 missing values**.

### Outliers and Anomalies
- **Negative Traffic Values:** The `value` column in the traffic dataset has a minimum value of **-27**. Assuming this represents a physical count of vehicles or traffic flow, negative numbers are physically impossible and represent anomalous readings, sensor errors, or special null-equivalent codes (e.g., similar to a -99 placeholder). These must be filtered or imputed before training.
- **Traffic Maximums:** The maximum `value` is 2,691, with a mean of 13.3 and a 75th percentile of 10. The large max value may represent sudden heavy bursts of traffic or aggregated anomalies.

### Class Imbalances / Distributions
- **Traffic `category`:** Heavily imbalanced towards `'flow'` (20.5M out of 21.1M records). 
- **Traffic `veh_class`:** The most frequent class is `'person'` (6.8M records), though there are 16 unique vehicle classes overall.
- **Traffic `dir` (Direction):** 'east_to_west' is the most heavily represented direction (4.1M records) out of 122 unique directions.
- **Weather `variable`:** Dominated by `'Humidity'` (1.38M out of 2.7M records) and collected predominantly by the `aq_mesh_api` broker.

## 4. Next Steps for Pipeline Design
1. **Data Cleaning:** Drop `units` from weather data. Filter or handle negative `value` anomalies in the traffic dataset.
2. **Temporal Alignment:** Re-index the traffic dataset to a continuous 15-minute time series (resampling and filling gaps with zeros or imputed values) to restore physical continuity.
3. **Data Integration:** Use spatial coordinates (from the JSON files) to map traffic sensors to the nearest weather sensors, subsequently merging the dataframes on datetime (`dt` and `timestamp`) and location identifiers.
4. **Feature Engineering:** Extract temporal features (hour, day of week, month) from the datetimes, pivot weather variables to columns, and aggregate traffic volumes to a consistent time-frequency (e.g., hourly).

# Objective

Implement a Geospatial Digital Twin for the Resilient IoT network. This frontend must visualise complex spatiotemporal graph inferences, including Zero-Inflated Negative Binomial (ZINB) predictions, mathematical uncertainty bounds, and dynamic graph attention weights. It must be highly performant, capable of rendering thousands of animating nodes and edges at 60fps across a sliding time window.

## 1. Core Tech Stack

- Framework: Next.js (React) with TypeScript (Strict mode enabled).
- Geospatial Engine: Deck.gl (by Uber) running over a MapLibre GL JS base map. Standard mapping libraries (Leaflet, Mapbox standard) are banned for data layers to prevent DOM overload. Deck.gl WebGL layers must be used for all data rendering.
- State Management: Zustand. Required to decouple the rapid time-slider updates from the React render cycle, preventing the entire DOM from re-rendering when only WebGL properties need to change.
- Database & Spatial Backend: Supabase (PostgreSQL + PostGIS) for road-network mapping and spatial interpolations.

## 2. Architectural Components (The Visual Layers)

The UI is built on independent, composable Deck.gl layers that consume the ui_payload.json (and eventually Supabase API endpoints).

### A. The Node Layer (Predictions & Uncertainty)

- Component: Deck.gl ScatterplotLayer.
- Data Source: Sensor locations (real) and Simulated Nodes.
- Visual Mapping:
  - Fill Color (Prediction): Mapped to the ZINB $\mu$ parameter (mean predicted traffic). Use a sequential color scale (e.g., Green $\rightarrow$ Yellow $\rightarrow$ Red).
  - Stroke/Halo Radius (Uncertainty): Mapped to the 95% Confidence Interval derived from the ZINB $\theta$ (dispersion) parameter. A wider, semi-transparent radius indicates high model uncertainty.
  - Simulated Nodes: Visually distinct (e.g., using a dashed stroke or distinct shape) to indicate the prediction is a zero-shot topological inference, not a physical sensor.

### B. The Topology Layer (Attention Weights)

- Component: Deck.gl ArcLayer or LineLayer.
- Data Source: The attention_sequence extracted from the GATv2Conv layers.
- Visual Mapping:
  - Source/Target: Sensor coordinates.
  - Opacity/Width: Mapped to the attention weight ($\alpha$).
  - Filtering Rule: To prevent visual clutter ("hairballs"), the frontend must aggressively filter this layer, only rendering the top N attention edges for the current timestep, or only rendering edges connected to a user-selected node.

### C. The Road-Constrained Heatmap (Spatial Interpolation)

- Component: Deck.gl PathLayer rendering GeoJSON LineStrings.
- Data Source: OpenStreetMap street networks, processed via PostGIS.
- Mechanism: Rather than rendering a blurry traditional heatmap, point predictions are snapped to the road network. PostGIS functions (ST_ClosestPoint, ST_Distance) interpolate the ZINB $\mu$ values between adjacent sensors to color-code continuous road segments representing traffic flow.

## 3. State Management & Time Travel

- The core UX revolves around temporal exploration. State is managed globally via a Zustand store (useTimeStore).
- The Global Clock: A single integer state (`currentTimestep`) representing the index of the 15-minute window (e.g., 0 to 96 for a 24-hour forecast).
- Interpolation Logic: Deck.gl layers must linearly interpolate positions, colors, and radii between timestep[t] and timestep[t+1] to provide smooth animation as the user drags the time slider.
- Data Slicing: The React components do not filter the massive data payload. The Deck.gl layers receive the full data arrays and use DataFilterExtension (a WebGL shader extension) to efficiently hide/show data based on `currentTimestep` on the GPU.

## 4. Phased Implementation Strategy

### Phase 1: The Static Prototype (Memory-Bound)

- Goal: Validate the visual paradigm without setting up databases.
- Mechanism: The Next.js app loads ui_payload.json (generated by the PyTorch backend) directly into browser memory.
- Deliverables: Node Layer (predictions + uncertainty halos) and Topology Layer (attention arcs) linked to a basic React slider.

### Phase 2: PostGIS Migration (The Road Network)

- Goal: Implement the Road-Constrained Heatmap.
- Mechanism: Spin up Supabase. Ingest the city's road GeoJSON. Write the SQL views that dynamically join the ui_payload predictions to the road segments.
- Deliverables: The PathLayer successfully renders continuous traffic flows.

### Phase 3: Production API Integration

- Goal: Live inference.
- Mechanism: Replace the static JSON payload with authenticated API calls to a deployed version of the ResilientIoTPipeline serving live ZINB parameters.

import pandas as pd
import numpy as np

def check_traffic_gaps(file_path: str):
    df = pd.read_parquet(file_path)
    print(f"Loaded {len(df)} rows.")
    
    # Sort by location, category, veh_class, dir, and dt
    df = df.sort_values(['location', 'category', 'veh_class', 'dir', 'dt'])
    
    # Calculate time difference between consecutive rows within the same groups
    df['dt_diff'] = df.groupby(['location', 'category', 'veh_class', 'dir'])['dt'].diff()
    
    # Get stats on the gaps
    gaps = df['dt_diff'].dropna()
    print("\nGap Statistics (Time Deltas):")
    print(gaps.describe())
    
    # Count large gaps (e.g., > 15 minutes if data is expected to be more frequent)
    # Let's see what the most common frequency is first.
    mode_diff = gaps.mode()[0]
    print(f"\nMost common gap (Mode): {mode_diff}")
    
    large_gaps = gaps[gaps > mode_diff]
    print(f"Number of gaps larger than mode: {len(large_gaps)} ({len(large_gaps)/len(gaps)*100:.2f}%)")
    
    print("\nSample of large gaps:")
    print(large_gaps.value_counts().head(10))

if __name__ == "__main__":
    check_traffic_gaps('data/traffic_20230108_20260108.parquet')

        logger.info(f"Loading data from {parquet_path} between {start_date} and {end_date}")
        
        # 1. Load Data with Time Filter Constraints
        start_dt = pd.Timestamp(start_date)
        end_dt = pd.Timestamp(end_date)
        
        df = pd.read_parquet(
            parquet_path,
            filters=[
                ('dt', '>=', start_dt), 
                ('dt', '<', end_dt)
            ],
            columns=['dt', 'location', 'value', 'Humidity', 'Solar Radiation', 'nearby_poi_count', 'dist_to_nearest_intersection', 'veh_class', 'dir']
        )
        
        if df.empty:
            raise ValueError(f"No data found for the specified date range: {start_date} to {end_date}")

        available_classes = sorted(df['veh_class'].dropna().astype(str).unique().tolist())
        available_dirs = sorted(df['dir'].dropna().astype(str).unique().tolist())
            
        # 2. Filter target stream to ensure unique (dt, location) indices
        df = df[df['veh_class'] == target_veh_class]
        if df.empty:
            raise ValueError(
                f"No rows after veh_class filter. Requested veh_class='{target_veh_class}' "
                f"for range {start_date} to {end_date}. Available veh_class values: {available_classes}"
            )
        
        if target_dir == 'all':
            # Group by dt and location, sum values, take first for weather/static features
            agg_funcs = {
                'value': 'sum',
                'Humidity': 'first',
                'Solar Radiation': 'first',
                'nearby_poi_count': 'first',
                'dist_to_nearest_intersection': 'first'
            }
            df = df.groupby(['dt', 'location'], as_index=False).agg(agg_funcs)
        else:
            df = df[df['dir'] == target_dir]
            if df.empty:
                raise ValueError(
                    f"No rows after dir filter. Requested dir='{target_dir}' with veh_class='{target_veh_class}' "
                    f"for range {start_date} to {end_date}. Available dir values before filtering: {available_dirs}"
                )

        if df.empty:
            raise ValueError(
                f"No rows available after filtering and aggregation for range {start_date} to {end_date}, "
                f"veh_class='{target_veh_class}', dir='{target_dir}'."
            )
            
        # 3. Extract dimensions
        self.locations = sorted(df['location'].unique())
        self.times = sorted(df['dt'].unique())
        self.seq_len = seq_len
        self.mask_prob = mask_prob
        self.num_nodes = len(self.locations)
        
        logger.info(f"Loaded {len(self.times)} timesteps across {self.num_nodes} locations for class={target_veh_class}, dir={target_dir}.")
        
        # 4. Pivot for Sliding Window Logic
        df = df.set_index(['dt', 'location'])
        
        # Dynamic features
        dyn_df = df[['value', 'Humidity', 'Solar Radiation']].unstack('location')
        locations_idx = pd.Index(self.locations, name='location')
        
        val_arr = dyn_df['value'].reindex(columns=locations_idx).fillna(0.0).values
        hum_arr = dyn_df['Humidity'].reindex(columns=locations_idx).fillna(0.0).values
        sol_arr = dyn_df['Solar Radiation'].reindex(columns=locations_idx).fillna(0.0).values

        # Preserve a raw, unscaled copy of traffic counts BEFORE any scaling.
        # ZINB NLL requires non-negative counts as targets; StandardScaler would
        # convert these to signed floats and corrupt the loss domain.
        self.unscaled_traffic = val_arr.copy()  # [num_times, num_nodes]

        # [num_times, num_nodes, 3]
        self.dynamic_data = np.stack([val_arr, hum_arr, sol_arr], axis=-1)
        self.time_series_dim = self.dynamic_data.shape[-1]

        # Scale dynamic features across the full dataset so the model receives
        # zero-mean, unit-variance inputs — critical for stable gradient flow.
        num_times, num_nodes_d, n_dyn_features = self.dynamic_data.shape
        dyn_flat = self.dynamic_data.reshape(-1, n_dyn_features)
        self.scaler = StandardScaler()
        dyn_scaled = self.scaler.fit_transform(dyn_flat)
        self.dynamic_data = dyn_scaled.reshape(num_times, num_nodes_d, n_dyn_features)
        logger.info(f"Dynamic features scaled: mean≈0, std≈1 over {num_times * num_nodes_d} samples.")

        # Static features
        stat_df = df[['nearby_poi_count', 'dist_to_nearest_intersection']].groupby('location').first()
        stat_df = stat_df.reindex(locations_idx).fillna(0.0)

        # Scale static features so DynamicGraphLearner receives normalised coordinates/metadata.
        stat_np = stat_df.values  # [num_nodes, static_feat_dim]
        self.static_scaler = StandardScaler()
        stat_np_scaled = self.static_scaler.fit_transform(stat_np)
        self.static_features = torch.tensor(stat_np_scaled, dtype=torch.float32)
        self.static_feat_dim = self.static_features.shape[-1]
        logger.info(f"Static features scaled: mean≈0, std≈1 over {stat_np.shape[0]} nodes.")
        
        logger.info(f"Feature dimensions established. Static: {self.static_feat_dim}, Dynamic: {self.time_series_dim}")

    def __len__(self) -> int:
        return max(0, len(self.times) - self.seq_len)

    def __getitem__(self, idx: int) -> dict:
        # Extract sliding window
        # Dynamic: [seq_len, num_nodes, D] -> permute -> [num_nodes, seq_len, D]
        dyn_slice = self.dynamic_data[idx : idx + self.seq_len]
        dyn_slice = np.transpose(dyn_slice, (1, 0, 2))
        
        dyn_tensor = torch.tensor(dyn_slice, dtype=torch.float32)

        # Forecast target: pull from unscaled traffic counts, not scaled dynamic_data.
        # clamp(min=0) is a hard tripwire — raw counts must never be negative,
        # but guards against any residual float precision artifacts from the parquet.
        target = self.unscaled_traffic[idx + self.seq_len]  # [num_nodes]
        target_tensor = torch.tensor(target, dtype=torch.float32).clamp(min=0)
        
        # 4. Dynamic Masking logic (~15% artificial NaN injection)
        node_mask = torch.rand_like(dyn_tensor) < self.mask_prob
        target_impute = dyn_tensor.clone()
        dyn_masked = dyn_tensor.clone()
        dyn_masked[node_mask] = float('nan')

        return {
            'static_features': self.static_features,
            'dynamic_features': dyn_masked,
            'target_impute': target_impute,
            'target_forecast': target_tensor,
            'node_mask': node_mask
        }

def custom_collate_real(batch_list):

    }

import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Tuple, Optional

class DecoupledDecoders(nn.Module):
    """
    DecoupledDecoders: Multi-task heads for imputation and uncertainty-aware forecasting.
    """
    def __init__(self, hidden_dim: int, time_series_dim: int):
        super(DecoupledDecoders, self).__init__()

        # Reproducibility
        torch.manual_seed(42)

        self.hidden_dim = hidden_dim
        self.time_series_dim = time_series_dim

        # Imputation Decoder: Reconstructs the entire sequence.
        # Deepened to a 2-layer MLP to give the model enough capacity to recover
        # masked sensor readings from the latent graph representation.
        self.impute_layer = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 2),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim * 2, time_series_dim)
        )

        # Forecasting Decoder: Predicts ZINB parameters (mu, theta, pi).
        # Deepened to match imputation head capacity and reduce gradient starvation.
        self.forecast_layer = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 2),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(hidden_dim * 2, 3)
        )

    def forward(self, latent_embeddings: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor]:
        """
        Args:
            latent_embeddings: [batch_size, num_nodes, seq_len, hidden_dim]
        Returns:
            imputed_features: [batch_size, num_nodes, seq_len, time_series_dim]
            mu: [batch_size, num_nodes]
            theta: [batch_size, num_nodes]
            pi: [batch_size, num_nodes]
        """
        assert latent_embeddings.dim() == 4, f"Expected 4D embeddings, got {latent_embeddings.shape}"
        batch_size, num_nodes, seq_len, hidden_dim = latent_embeddings.shape

        # 1. Imputation (across all time steps)
        imputed_features = self.impute_layer(latent_embeddings)

        # 2. Forecasting (using the final time step's embedding)
        last_step_embedding = latent_embeddings[:, :, -1, :] # [batch_size, num_nodes, hidden_dim]
        forecast_logits = self.forecast_layer(last_step_embedding) # [batch_size, num_nodes, 3]

        # Split raw logits
        mu_logits = forecast_logits[:, :, 0]
        theta_logits = forecast_logits[:, :, 1]
        pi_logits = forecast_logits[:, :, 2]

        # Apply ZINB constraints (Tripwires from ARCHITECTURE.md)
        eps = 1e-6
        pi = torch.sigmoid(pi_logits)
        mu = F.softplus(mu_logits) + eps
        theta = F.softplus(theta_logits) + eps

        return imputed_features, mu, theta, pi

def compute_zinb_nll(y_true: torch.Tensor, mu: torch.Tensor, theta: torch.Tensor, pi: torch.Tensor) -> torch.Tensor:
    """
    Negative Log-Likelihood for Zero-Inflated Negative Binomial Distribution.

    Formula:
    If y=0: P(y) = pi + (1-pi) * (theta / (theta + mu))^theta
    If y>0: P(y) = (1-pi) * [Gamma(y+theta)/(y!Gamma(theta))] * (theta/(theta+mu))^theta * (mu/(theta+mu))^y
    """
    eps = 1e-6
    y_true = y_true.float()

    # Clamp log operations to eps
    def safe_log(x):
        return torch.log(x.clamp(min=eps))

    # NB log-likelihood components
    # log(theta / (theta + mu))
    log_theta_mu_ratio = safe_log(theta) - safe_log(theta + mu)
    # log(mu / (theta + mu))
    log_mu_mu_ratio = safe_log(mu) - safe_log(theta + mu)

    # Case y > 0
    # log P(y|NB) = logGamma(y+theta) - logGamma(y+1) - logGamma(theta) + theta*log(theta/(theta+mu)) + y*log(mu/(theta+mu))
    ll_nb = (torch.lgamma(y_true + theta)
             - torch.lgamma(y_true + 1)
             - torch.lgamma(theta)
             + theta * log_theta_mu_ratio
             + y_true * log_mu_mu_ratio)

    # Case y = 0
    # P(y=0|ZINB) = pi + (1-pi) * exp(theta * log(theta/(theta+mu)))
    # For numerical stability, we use log-sum-exp or handle it carefully
    # log_p_zero_nb = theta * log_theta_mu_ratio
    ll_zero = safe_log(pi + (1 - pi) * torch.exp(theta * log_theta_mu_ratio))

    # Case y > 0 (ZINB)
    # log P(y|ZINB) = log(1-pi) + ll_nb
    ll_nonzero = safe_log(1 - pi) + ll_nb

    # Combine cases
    result = torch.where(y_true < eps, ll_zero, ll_nonzero)

    return -torch.mean(result)

def compute_loss(imputed_features: torch.Tensor,
                 target_impute: torch.Tensor,
                 mu: torch.Tensor,
                 theta: torch.Tensor,
                 pi: torch.Tensor,
                 target_forecast: torch.Tensor,
                 w_impute: float = 1.0,
                 w_forecast: float = 1.0) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    Joint Loss: MSE for Imputation + ZINB NLL for Forecasting.
    """
    # 1. Imputation Loss (MSE)
    # ARCHITECTURE.md: "strictly on the artificially masked nodes"
    # Note: In a real scenario, we'd use a mask here.
    loss_impute = F.mse_loss(imputed_features, target_impute)

    # 2. Forecasting Loss (ZINB NLL)
    loss_forecast = compute_zinb_nll(target_forecast, mu, theta, pi)

    # 3. Total Weighted Loss
    total_loss = (w_impute * loss_impute) + (w_forecast * loss_forecast)

    # --- Tripwires (Rule 5 & ARCHITECTURE.md) ---
    if torch.isnan(total_loss).any():
        # Print stats for debugging before crashing
        print(f"DEBUG: mu min={mu.min()}, max={mu.max()}")
        print(f"DEBUG: theta min={theta.min()}, max={theta.max()}")
        print(f"DEBUG: pi min={pi.min()}, max={pi.max()}")
        raise ValueError("CRITICAL FAILURE: Loss is NaN. Mathematical tripwire triggered.")

    return total_loss, loss_impute, loss_forecast

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GATv2Conv
from typing import Optional, Tuple, Union

class MaskedSpatiotemporalEncoder(nn.Module):
    """
    MaskedSpatiotemporalEncoder: Processes dynamic IoT data using GATv2 and Transformers.
    
    Architecture:
    1. Spatial: GATv2Conv layers applied independently across each time step.
    2. Temporal: TransformerEncoder to capture dependencies across the sequence.
    """
    def __init__(self, 
                 num_nodes: int, 
                 seq_len: int, 
                 time_series_dim: int, 
                 hidden_dim: int = 64, 
                 num_heads: int = 4, 
                 num_layers: int = 2,
                 dropout: float = 0.1):
        super(MaskedSpatiotemporalEncoder, self).__init__()
        
        # Reproducibility at initialization
        torch.manual_seed(42)
        
        self.num_nodes = num_nodes
        self.seq_len = seq_len
        self.time_series_dim = time_series_dim
        self.hidden_dim = hidden_dim

        # 1. Spatial Processing: GATv2Conv
        # We use a single layer for simplicity as per common IoT patterns, 
        # or can be extended to multiple.
        self.gat = GATv2Conv(
            in_channels=time_series_dim,
            out_channels=hidden_dim // num_heads,
            heads=num_heads,
            dropout=dropout,
            edge_dim=1 # For edge_weight
        )

        # 2. Temporal Processing: Transformer
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_dim,
            nhead=num_heads,
            dim_feedforward=hidden_dim * 4,
            dropout=dropout,
            batch_first=False # Standard Transformer [Seq, Batch, Dim]
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)

    def forward(
        self,
        dynamic_features: torch.Tensor,
        edge_index: torch.Tensor,
        edge_weight: torch.Tensor,
        return_attention_weights: bool = False,
    ) -> Union[torch.Tensor, Tuple[torch.Tensor, torch.Tensor]]:
        """
        Args:
            dynamic_features: [batch_size, num_nodes, seq_len, time_series_dim]
            edge_index: [2, E]
            edge_weight: [E]
            return_attention_weights: If True, also return the GAT attention
                coefficients alpha [batched_E, num_heads] for downstream analysis.
        Returns:
            latent_embeddings: [batch_size, num_nodes, seq_len, hidden_dim]
            alpha (optional): [batched_E, num_heads] — only when return_attention_weights=True.
        """
        # --- Defensive Data Handling (Rule 2) ---
        assert dynamic_features.dim() == 4, f"Expected 4D features, got {dynamic_features.shape}"
        batch_size, num_nodes, seq_len, ts_dim = dynamic_features.shape
        assert num_nodes == self.num_nodes, f"Node mismatch: {num_nodes} != {self.num_nodes}"
        assert seq_len == self.seq_len, f"Seq mismatch: {seq_len} != {self.seq_len}"
        assert ts_dim == self.time_series_dim, f"Feature mismatch: {ts_dim} != {self.time_series_dim}"

        # --- Spatial Processing ---
        # Reshape to [B, T, N, D] then to [B*T*N, D]
        # We want to apply GAT to each (batch, time_step) independently.
        x = dynamic_features.permute(0, 2, 1, 3).contiguous() # [B, T, N, D]
        x = x.view(batch_size * seq_len * num_nodes, ts_dim)

        # Construct batched edge_index
        # Original edge_index is [2, E] for num_nodes.
        # We need to repeat it batch_size * seq_len times with offsets.
        num_graphs = batch_size * seq_len
        E = edge_index.shape[1]
        
        # [2, E * num_graphs]
        batched_edge_index = edge_index.repeat(1, num_graphs)
        offsets = torch.arange(num_graphs, device=edge_index.device).view(-1, 1) * num_nodes
        # offsets shape: [num_graphs, 1]. Repeat for each edge in the graph.
        offsets = offsets.repeat(1, E).view(-1) # [num_graphs * E]
        batched_edge_index = batched_edge_index + offsets
        
        # edge_weight also needs repeating
        batched_edge_weight = edge_weight.repeat(num_graphs)

        # Apply GAT — optionally collect attention coefficients for analysis.
        if return_attention_weights:
            # PyG returns (out, (edge_index_used, alpha)) when return_attention_weights=True
            x_spatial, (_, alpha) = self.gat(
                x, batched_edge_index,
                edge_attr=batched_edge_weight,
                return_attention_weights=True,
            )
        else:
            x_spatial = self.gat(x, batched_edge_index, edge_attr=batched_edge_weight)
            alpha = None

        # --- Temporal Processing ---
        # Reshape back to [B, T, N, H]
        x_temporal = x_spatial.view(batch_size, seq_len, num_nodes, self.hidden_dim)
        
        # Transformer expects [Seq, Batch, Dim]
        # We treat each node in each batch as an independent sequence.
        # Batch dimension for Transformer: B * N
        # Seq dimension: T
        x_temporal = x_temporal.permute(1, 0, 2, 3).contiguous() # [T, B, N, H]
        x_temporal = x_temporal.view(seq_len, batch_size * num_nodes, self.hidden_dim)

        # Pass through Transformer
        # x_out: [T, B * N, H]
        x_out = self.transformer(x_temporal)

        # Reshape back to [B, N, T, H]
        x_out = x_out.view(seq_len, batch_size, num_nodes, self.hidden_dim)
        x_out = x_out.permute(1, 2, 0, 3).contiguous() # [B, N, T, H]

        # --- Tripwires (Rule 5) ---
        if torch.isnan(x_out).any():
            raise ValueError("NaN detected in MaskedSpatiotemporalEncoder output!")

        if return_attention_weights:
            return x_out, alpha
        return x_out

        logger.info("Static feature enrichment complete.")
        return df

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.utils import dense_to_sparse
from typing import Tuple

class DynamicGraphLearner(nn.Module):
    """
    DynamicGraphLearner: Infers graph topology from static node features.
    
    Architecture:
    1. Linear projection to latent space.
    2. Pairwise dot-product similarity to form adjacency matrix.
    3. ReLU and tunable sparsity thresholding.
    4. Sparse conversion to (edge_index, edge_weight).
    """
    def __init__(self, static_feat_dim: int, embedding_dim: int = 32, sparsity_threshold: float = 0.5):
        super(DynamicGraphLearner, self).__init__()
        # Ensure random seeds are handled globally or at the top of the script
        
        self.static_feat_dim = static_feat_dim
        self.embedding_dim = embedding_dim
        
        # Parameterized projection layer
        self.lin = nn.Linear(static_feat_dim, embedding_dim)
        
        # Tunable sparsity threshold (can be a learned parameter if needed, but here a buffer/float)
        self.register_buffer('sparsity_threshold', torch.tensor(sparsity_threshold))

    def forward(self, static_features: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Forward pass:
        Args:
            static_features: [num_nodes, static_feat_dim]
        Returns:
            edge_index: [2, E]
            edge_weight: [E]
        """
        assert static_features.dim() == 2, f"Expected static_features shape [num_nodes, static_feat_dim], got {static_features.shape}"
        assert static_features.shape[1] == self.static_feat_dim, f"Feature dimension mismatch: {static_features.shape[1]} != {self.static_feat_dim}"

        num_nodes = static_features.shape[0]

        # 1. Project to embedding space
        # [num_nodes, embedding_dim]
        embeddings = self.lin(static_features)

        # 2. Pairwise dot-product similarity
        # [num_nodes, num_nodes]
        adj = torch.matmul(embeddings, embeddings.t())

        # 3. Apply ReLU to ensure non-negative weights
        adj = F.relu(adj)

        # 4. Sparsity: Subtract threshold and apply ReLU
        # This drops connections with weights <= sparsity_threshold
        adj = adj - self.sparsity_threshold
        adj = F.relu(adj)

        # 5. Convert to sparse format
        edge_index, edge_weight = dense_to_sparse(adj)

        return edge_index, edge_weight

import torch
import numpy as np
from typing import Dict, Union

def calculate_metrics(
    target_forecast: torch.Tensor,
    mu: torch.Tensor,
    pi: torch.Tensor,
    imputed_features: torch.Tensor,
    target_impute: torch.Tensor,
    node_mask: torch.Tensor
) -> Dict[str, Union[float, int]]:
    """
    Calculates human-readable metrics for the ResilientIoTPipeline.

    Args:
        target_forecast: [batch_size, num_nodes] Ground truth future counts.
        mu: [batch_size, num_nodes] Predicted ZINB mean.
        pi: [batch_size, num_nodes] Predicted zero-inflation probability.
        imputed_features: [batch_size, num_nodes, seq_len, time_series_dim] Reconstructed features.
        target_impute: [batch_size, num_nodes, seq_len, time_series_dim] Ground truth historical features.
        node_mask: [batch_size, num_nodes, seq_len, time_series_dim] Mask where NaNs were artificially applied.

    Returns:
        Dict with keys: rmse (float), mae (float), impute_mse (float),
        zero_true_count (int), zero_correct_count (int).
    """
    # 1. RMSE and MAE (Forecasting)
    # mu is predicted mean count
    mse_forecast = torch.mean((target_forecast - mu)**2)
    rmse = torch.sqrt(mse_forecast).item()
    mae = torch.mean(torch.abs(target_forecast - mu)).item()

    # 2. Zero-Accuracy counts (aggregated by caller to avoid batch-averaging bias)
    # zero_true_count: number of positions where target_forecast == 0
    # zero_correct_count: among those, how many have pi > 0.5
    zero_indices = (target_forecast == 0)
    zero_true_count: int = int(zero_indices.sum().item())
    if zero_true_count > 0:
        zero_correct_count: int = int((pi[zero_indices] > 0.5).sum().item())
    else:
        zero_correct_count = 0

    # 3. Imputation MSE
    # Calculate MSE strictly where node_mask is True (the artificial NaNs)
    if node_mask.any():
        # Ensure node_mask matches the shape of imputed_features/target_impute
        # Based on src/train.py mock data, node_mask has the same shape as dynamic_features [B, N, T, D]
        diff_sq = (imputed_features - target_impute)**2
        impute_mse = torch.mean(diff_sq[node_mask]).item()
    else:
        impute_mse = 0.0

    return {
        "rmse": rmse,
        "mae": mae,
        "zero_true_count": zero_true_count,
        "zero_correct_count": zero_correct_count,
        "impute_mse": impute_mse
    }

import torch
import torch.nn as nn
from torch.utils.data import DataLoader
import logging

from graph_learner import DynamicGraphLearner
from encoder import MaskedSpatiotemporalEncoder
from decoders import DecoupledDecoders, compute_loss
from dataset import RealIoTDataset

from typing import Dict, Tuple, Union

logger = logging.getLogger(__name__)

class ResilientIoTPipeline(nn.Module):
    """
    ResilientIoTPipeline: End-to-end spatiotemporal model for IoT sensor networks.
    Integrates Topology Inference, Spatiotemporal Encoding, and Multi-Task Decoders.
    """
    def __init__(self,
                 num_nodes: int,
                 static_feat_dim: int,
                 time_series_dim: int,
                 seq_len: int,
                 embedding_dim: int = 32,
                 hidden_dim: int = 64,
                 sparsity_threshold: float = 0.5):
        super(ResilientIoTPipeline, self).__init__()

        # 1. Topology Inference
        self.graph_learner = DynamicGraphLearner(
            static_feat_dim=static_feat_dim,
            embedding_dim=embedding_dim,
            sparsity_threshold=sparsity_threshold
        )
        logger.info(f"Initialized DynamicGraphLearner with static_feat_dim={static_feat_dim}, embedding_dim={embedding_dim}, sparsity_threshold={sparsity_threshold}, total_params={sum(p.numel() for p in self.graph_learner.parameters())}")

        # 2. Spatiotemporal Feature Extraction
        self.encoder = MaskedSpatiotemporalEncoder(
            num_nodes=num_nodes,
            seq_len=seq_len,
            time_series_dim=time_series_dim,
            hidden_dim=hidden_dim
        )
        logger.info(f"Initialized MaskedSpatiotemporalEncoder with num_nodes={num_nodes}, seq_len={seq_len}, time_series_dim={time_series_dim}, hidden_dim={hidden_dim}, total_params={sum(p.numel() for p in self.encoder.parameters())}")

        # 3. Multi-Task Decoders
        self.decoders = DecoupledDecoders(
            hidden_dim=hidden_dim,
            time_series_dim=time_series_dim
        )
        logger.info(f"Initialized DecoupledDecoders with hidden_dim={hidden_dim}, time_series_dim={time_series_dim}, total_params={sum(p.numel() for p in self.decoders.parameters())}")

    def forward(
        self,
        batch: dict,
        return_analysis: bool = False,
    ) -> Union[Tuple[torch.Tensor, ...], Dict[str, torch.Tensor]]:
        """
        Args:
            batch (dict): Expected keys:
                - static_features: [num_nodes, static_feat_dim]
                - dynamic_features: [batch_size, num_nodes, seq_len, time_series_dim]
                - target_forecast: [batch_size, num_nodes]
                - target_impute: [batch_size, num_nodes, seq_len, time_series_dim]
                - node_mask: [batch_size, num_nodes, seq_len, time_series_dim]
            return_analysis: If True, bypass loss calculation and return a dict
                containing the inferred graph structure and GAT attention weights
                for post-hoc interpretability analysis.
        Returns:
            Normal mode: (total_loss, loss_impute, loss_forecast, imputed_features, mu, theta, pi)
            Analysis mode: {'edge_index', 'edge_weight', 'attention_weights'}
        """
        static_features = batch['static_features']
        dynamic_features = batch['dynamic_features']
        target_forecast = batch['target_forecast']
        target_impute = batch['target_impute']

        # Defensive Data Handling
        # Replace NaNs (injected by our Dataset masking) with 0.0 to allow PyTorch ops
        dynamic_features_clean = torch.nan_to_num(dynamic_features, nan=0.0)

        # 1. Graph Learner
        edge_index, edge_weight = self.graph_learner(static_features)

        # 2. Encoder — request attention weights when in analysis mode
        if return_analysis:
            latent_embeddings, alpha = self.encoder(
                dynamic_features_clean, edge_index, edge_weight,
                return_attention_weights=True,
            )
            return {
                'edge_index': edge_index,
                'edge_weight': edge_weight,
                'attention_weights': alpha,
            }

        latent_embeddings = self.encoder(dynamic_features_clean, edge_index, edge_weight)

        # 3. Decoders
        imputed_features, mu, theta, pi = self.decoders(latent_embeddings)

        # 4. Compute Joint Loss
        loss, loss_impute, loss_forecast = compute_loss(
            imputed_features=imputed_features,
            target_impute=target_impute,
            mu=mu,
            theta=theta,
            pi=pi,
            target_forecast=target_forecast
        )

        # CRITICAL SAFEGUARD
        assert not torch.isnan(loss).any(), "CRITICAL FAILURE: Pipeline total_loss is NaN."

        return loss, loss_impute, loss_forecast, imputed_features, mu, theta, pi

import logging

import pandas as pd

class SensorMappingError(Exception):
    """Custom exception raised when spatial join fails to map a traffic sensor to a weather sensor."""
    pass


class PreprocessingPipeline:
    def __init__(self, frequency: str = '15min'):
        self.frequency = frequency
        logger.info(f"Initialized PreprocessingPipeline with frequency: {self.frequency}")

    def resample_traffic(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Resamples the irregular traffic data into a continuous frequency grid.
        Missing timestamps will reappear as explicit NaN rows.
        """
        logger.info(f"Starting resample_traffic. Input shape: {df.shape}")

        # Assertion: Input dataframe is not empty
        assert not df.empty, "Input dataframe is empty."
        
        # Assertion: Contains required columns
        required_cols = ['location', 'category', 'veh_class', 'dir', 'dt', 'value']
        for col in required_cols:
            assert col in df.columns, f"Missing required column: {col}"

        if not pd.api.types.is_datetime64_any_dtype(df['dt']):
            df['dt'] = pd.to_datetime(df['dt'])

        # Handle physical impossibilities (negative values) before resampling
        # Tripwire: Ensure no silent suppression, explicitly convert anomalous negatives to NaN
        df.loc[df['value'] < 0, 'value'] = np.nan

        # Generate the global target grid
        min_dt = df['dt'].min().floor(self.frequency)
        max_dt = df['dt'].max().ceil(self.frequency)
        expected_index = pd.date_range(start=min_dt, end=max_dt, freq=self.frequency, name='dt')

        # Group and resample
        groups = ['location', 'category', 'veh_class', 'dir']
        
        # We'll build the continuous grid for each group explicitly
        resampled_list = []
        unique_groups = df[groups].drop_duplicates().dropna(subset=groups)
        
        for _, row in unique_groups.iterrows():
            logger.info(f"DEBUG: Processing group: {row.to_dict()}")
            group_mask = True
            for col in groups:
                group_mask &= (df[col] == row[col])
            
            group_df = df[group_mask].set_index('dt')
            # Resample and reindex to global grid
            group_resampled = group_df['value'].resample(self.frequency).sum(min_count=1).reindex(expected_index)
            
            # Reconstruct the group columns
            temp_df = group_resampled.reset_index()
            # If the index was named 'dt', it appears as 'dt'. If unnamed, it appears as 'index'.
            if 'index' in temp_df.columns:
                temp_df = temp_df.rename(columns={'index': 'dt'})
            
            # Ensure the value column is correctly named
            potential_value_cols = [c for c in temp_df.columns if c != 'dt']
            if potential_value_cols:
                temp_df = temp_df.rename(columns={potential_value_cols[0]: 'value'})
            for col in groups:
                temp_df[col] = row[col]
            
            resampled_list.append(temp_df)
        
        final_df = pd.concat(resampled_list, ignore_index=True)

        # Grid Validation Tripwire
        observed_groups = df[groups].drop_duplicates()
        expected_total_rows = len(observed_groups) * len(expected_index)
        assert len(final_df) == expected_total_rows, (
            f"Grid validation failed: Expected {expected_total_rows} rows, "
            f"but got {len(final_df)}."
        )

        logger.info(f"Resampling complete. Output shape: {final_df.shape}")
        return final_df

    def impute_missingness(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Missingness-Aware Imputation Strategy.
        Prioritizes 'Missing Zero' imputation and leaves true gaps as NaN.
        """
        logger.info(f"Starting impute_missingness. Input shape: {df.shape}")
        assert not df.empty, "Dataframe is empty before imputation."
        assert 'dt' in df.columns and 'value' in df.columns, "Missing 'dt' or 'value' columns."
        
        # Priority 1: Structural Missingness (Zero-Priority)
        # Using a simple contextual heuristic: If it's late night (00:00 to 04:59), assume missing means 0 traffic.
        hour = df['dt'].dt.hour
        is_night = (hour >= 0) & (hour < 5)
        
        structural_zero_mask = df['value'].isna() & is_night
        df.loc[structural_zero_mask, 'value'] = 0.0
        
        # Priority 2: True Gaps
        # All other NaN values remain as NaN to maintain missingness awareness.
        # Explicitly DO NOT use .fillna(method='ffill') or .dropna()
        
        logger.info(f"Imputation complete. Remaining explicit NaNs: {df['value'].isna().sum()}")
        return df

    def spatial_join(self, traffic_df: pd.DataFrame, traffic_sensors: List[Dict], weather_sensors: List[Dict]) -> pd.DataFrame:
        """
        Maps each traffic sensor to the nearest weather sensor using spatial coordinates.
        """
        logger.info("Starting spatial_join.")
        assert not traffic_df.empty, "Traffic dataframe is empty."
        assert len(traffic_sensors) > 0, "No traffic sensors provided."
        assert len(weather_sensors) > 0, "No weather sensors provided."

        # Spatial Edge Case: N=1 weather sensors
        if len(weather_sensors) == 1:
            logger.info("Only 1 weather sensor found. Bypassing distance matrix calculation.")
            weather_sensor_name = weather_sensors[0].get('Sensor_Name')
            assert weather_sensor_name is not None, "Weather sensor missing 'Sensor_Name'."
            nearest_mapping = {ts['location']: weather_sensor_name for ts in traffic_sensors}
        else:
            logger.info(f"Calculating distance matrix for {len(weather_sensors)} weather sensors.")
            nearest_mapping = {}
            for ts in traffic_sensors:
                assert 'lat' in ts and 'lon' in ts, f"Traffic sensor missing lat/lon: {ts}"
                
                min_dist = float('inf')
                best_ws = None
                
                for ws in weather_sensors:
                    assert 'Sensor_Centroid_Latitude' in ws and 'Sensor_Centroid_Longitude' in ws, (
                        f"Weather sensor missing coordinates: {ws}"
                    )
                    
                    dy = ts['lat'] - ws['Sensor_Centroid_Latitude']
                    dx = ts['lon'] - ws['Sensor_Centroid_Longitude']
                    dist = dy**2 + dx**2  # Simplified squared distance (Euclidean approximation of Haversine)
                    
                    if dist < min_dist:
                        min_dist = dist
                        best_ws = ws.get('Sensor_Name')
                
                if best_ws is None:
                    raise SensorMappingError(f"Failed to map traffic sensor {ts['location']} to any weather sensor.")
                
                nearest_mapping[ts['location']] = best_ws

        traffic_df['nearest_weather_sensor'] = traffic_df['location'].map(nearest_mapping)

        # No Silent Drops: Crash if spatial join fails for any location
        if traffic_df['nearest_weather_sensor'].isna().any():
            unmapped = traffic_df[traffic_df['nearest_weather_sensor'].isna()]['location'].unique()
            raise SensorMappingError(f"Spatial join failed to find sensor mapping for locations: {unmapped}")

        logger.info(f"Spatial join complete. Output shape: {traffic_df.shape}")
        return traffic_df

    def enrich_static_features(self, df: pd.DataFrame) -> pd.DataFrame:
        """
        Defines the schema and integrates external static metadata features per sensor location.
        """
        logger.info("Starting enrich_static_features.")
        assert 'location' in df.columns, "Location column missing for static features."

        unique_locs = df['location'].unique()
        
        # Schema Definition for Google Places API integration
        mock_metadata = pd.DataFrame({
            'location': unique_locs,
            'highway_proximity': np.nan,  # Float: Distance to nearest major highway
            'commercial_density': np.nan, # Float: Number of commercial POIs in radius
            'school_zone': False          # Boolean: Inside/adjacent to a school zone
        })
        
        # Merge static features into the main dataframe
        df = df.merge(mock_metadata, on='location', how='left')
        
        # Assert features were successfully attached
        for col in ['highway_proximity', 'commercial_density', 'school_zone']:
            assert col in df.columns, f"Failed to integrate static feature: {col}"
            
        logger.info(f"Static feature enrichment complete. Output shape: {df.shape}")
        return df

def prepare_weather_data(weather_path: str, frequency: str = '15min') -> pd.DataFrame:
    """Loads, pivots, and resamples weather data to the target frequency."""
    logger.info("Loading weather data...")
    df = pd.read_parquet(weather_path)
    
    # Drop units as per EDA
    if 'units' in df.columns:
        df = df.drop(columns=['units'])
        
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    
    logger.info("Pivoting weather data...")
    pivoted = df.pivot_table(
        index=['sensor_name', 'timestamp'],
        columns='variable',
        values='value',
        aggfunc='mean'
    ).reset_index()
    
    logger.info("Resampling weather data to %s...", frequency)
    # Resample weather data to ensure it aligns with the 15min grid
    # We will set index to timestamp, group by sensor_name, and resample
    def resample_weather(g):
        return g.set_index('timestamp').resample(frequency).mean()
        
    # Apply resampling
    resampled_weather = pivoted.groupby('sensor_name').apply(resample_weather)
    resampled_weather = resampled_weather.reset_index()
    
    logger.info(f"Weather data prepared. Shape: {resampled_weather.shape}")
    return resampled_weather

def process_full_dataset():
    traffic_path = 'data/traffic_20230108_20260108.parquet'
    weather_path = 'data/weather_20230108_20260108.parquet'
    output_dir = 'data/processed'

    os.makedirs(output_dir, exist_ok=True)
    
    with open('data/traffic_sensors.json', 'r') as f:
        traffic_sensors = json.load(f)
    with open('data/weather_sensors.json', 'r') as f:
        weather_sensors = json.load(f)

    # Prepare external datasets

    feature_loader = StaticFeatureLoader()
    pipeline = PreprocessingPipeline(frequency='15min')
    
    logger.info("Discovering unique locations in traffic data...")
    # Load just locations to get unique ones
    locs_df = pd.read_parquet(traffic_path, columns=['location'])
    unique_locations = locs_df['location'].unique()
    del locs_df
    gc.collect()
    
    logger.info(f"Found {len(unique_locations)} unique locations to process. Starting chunked processing...")
    
    # Process sequentially by location to be safe with RAM
    first_chunk = True
    processed_rows = 0
    
    # Read full traffic data into memory (21M rows, ~6 cols, fits in RAM easily, we just chunk the processing)
    # Actually, 21M rows is a bit large, let's load it and group by location.
    # To be extremely memory safe, we could read filters with pyarrow, but loading once is faster if it fits.
    # Let's try loading it once and chunking the DataFrame.
    full_traffic = pd.read_parquet(traffic_path)
    
    import pyarrow as pa
    import pyarrow.parquet as pq
    
    writer = None
    
    for loc in unique_locations:
        loc_df = full_traffic[full_traffic['location'] == loc].copy()
        
        # 1. Resample
        resampled_df = pipeline.resample_traffic(loc_df)
        
        # 2. Impute
        imputed_df = pipeline.impute_missingness(resampled_df)
        
        # 3. Spatial Join
        joined_df = pipeline.spatial_join(imputed_df, traffic_sensors, weather_sensors)
        
        # 4. Static Feature Join
        enriched_df = feature_loader.join_features(joined_df)
        
        # 5. Weather Time Series Join
        # Merge on nearest_weather_sensor and dt
        final_chunk = enriched_df.merge(
            weather_df,
            left_on=['nearest_weather_sensor', 'dt'],
            right_on=['sensor_name', 'timestamp'],
            how='left'
        )
        # Drop redundant columns from weather
        if 'sensor_name' in final_chunk.columns:
            final_chunk = final_chunk.drop(columns=['sensor_name'])
        if 'timestamp' in final_chunk.columns:
            final_chunk = final_chunk.drop(columns=['timestamp'])
            
        # Write to parquet file using pyarrow iterative writer
        table = pa.Table.from_pandas(final_chunk)
        if writer is None:
            writer = pq.ParquetWriter(output_file, table.schema)
        writer.write_table(table)
            
        processed_rows += len(final_chunk)
        logger.info(f"Processed location {loc}. Total accumulated rows: {processed_rows}")
        
        # Free memory
        del loc_df, resampled_df, imputed_df, joined_df, enriched_df, final_chunk, table
        gc.collect()

    if writer is not None:
        writer.close()

    logger.info(f"Full scale processing complete. Saved to {output_file}")
    logger.info(f"Total Rows: {processed_rows}")

if __name__ == "__main__":

class DivergenceError(Exception):
    """Custom exception raised when model loss diverges (NaNs)."""
    pass

def parse_args():
    parser = argparse.ArgumentParser(description="Train ResilientIoTPipeline")
    parser.add_argument("--epochs", type=int, default=2, help="Number of training epochs")
    parser.add_argument("--batch_size", type=int, default=4, help="Batch size")
    parser.add_argument("--lr", type=float, default=1e-3, help="Learning rate")
    parser.add_argument("--w_forecast", type=float, default=1.0, help="Weight for forecasting loss")
    parser.add_argument("--w_impute", type=float, default=1.0, help="Weight for imputation loss")
    
    # Dataset arguments
    parser.add_argument("--use_mock_data", action="store_true", help="Use mock data instead of real parquet data")
    parser.add_argument("--start_date", type=str, default="2023-03-02", help="Start date for real data (inclusive)")

    return parser.parse_args()

def create_mock_dataloader(batch_size: int, num_nodes: int, seq_len: int, time_series_dim: int, static_feat_dim: int, dataset_size: int):
    """
    Creates a mock DataLoader yielding batches that match the pipeline's expected dimensional structure.
    """
    class MockPipelineDataset(torch.utils.data.Dataset):
        def __init__(self, size):
            self.size = size
            self.static_feat_dim = static_feat_dim
            self.time_series_dim = time_series_dim
            self.num_nodes = num_nodes
            
        def __len__(self):
            return self.size
            
        def __getitem__(self, idx):
            dyn = torch.randn(num_nodes, seq_len, time_series_dim)
            mask = torch.rand_like(dyn) < 0.15
            dyn_masked = dyn.clone()
            dyn_masked[mask] = float('nan')
            
            return {
                'static_features': torch.randn(num_nodes, static_feat_dim),
                'dynamic_features': dyn_masked,
                'target_impute': dyn.clone(),
                'target_forecast': torch.randint(0, 50, (num_nodes,)).float(),
                'node_mask': mask
            }
            
    dataset = MockPipelineDataset(size=dataset_size)
    
    def custom_collate(batch_list):
        return {
            'static_features': batch_list[0]['static_features'], # Static across batch
            'dynamic_features': torch.stack([b['dynamic_features'] for b in batch_list]),
            'target_impute': torch.stack([b['target_impute'] for b in batch_list]),
            'target_forecast': torch.stack([b['target_forecast'] for b in batch_list]),
            'node_mask': torch.stack([b['node_mask'] for b in batch_list])
        }

    return DataLoader(dataset, batch_size=batch_size, collate_fn=custom_collate), dataset

def run_training(args, init_wandb=True) -> float:
    """
    Core execution logic for a single training run.
    Returns the final validation loss.
    """
    logger = logging.getLogger(__name__)

    # Reproducibility
    torch.manual_seed(42)
    np.random.seed(42)

    # Device configuration
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    logger.info(f"Using device: {device}")

    # Initialize W&B only if requested
    if init_wandb:
        wandb.init(project="resilient-iot", config=args)

    # Load Dataset
    if args.use_mock_data:
        logger.info("Using mock dataloader.")
        train_loader, train_dataset = create_mock_dataloader(args.batch_size, 50, args.seq_len, 3, 10, 20)
        val_loader, _ = create_mock_dataloader(args.batch_size, 50, args.seq_len, 3, 10, 8)
    else:
        logger.info(f"Loading RealIoTDataset from {args.start_date} to {args.end_date}")
        parquet_path = "data/processed/master_dataset_15T.parquet"
        try:
            full_dataset = RealIoTDataset(
                parquet_path, 
                args.start_date, 
                args.end_date, 
                seq_len=args.seq_len,
                target_veh_class=args.veh_class,
                target_dir=args.dir
            )
            
            train_size = int(0.8 * len(full_dataset))
            val_size = len(full_dataset) - train_size
            
            if train_size == 0 or val_size == 0:
                 raise ValueError("Not enough data to split into train and val. Try a wider date range.")
                 
            train_dataset, val_dataset = torch.utils.data.random_split(full_dataset, [train_size, val_size])
            
            train_dataset.num_nodes = full_dataset.num_nodes
            train_dataset.static_feat_dim = full_dataset.static_feat_dim
            train_dataset.time_series_dim = full_dataset.time_series_dim
            
            train_loader = DataLoader(train_dataset, batch_size=args.batch_size, collate_fn=custom_collate_real, shuffle=True)
            val_loader = DataLoader(val_dataset, batch_size=args.batch_size, collate_fn=custom_collate_real)
        except Exception as e:
            logger.error(f"Failed to load RealIoTDataset: {e}")
            raise

    # Model
    model = ResilientIoTPipeline(
        num_nodes=train_dataset.num_nodes,
        static_feat_dim=train_dataset.static_feat_dim,
        time_series_dim=train_dataset.time_series_dim,
        seq_len=args.seq_len
    ).to(device)

    # Optimizer
    optimizer = torch.optim.Adam(model.parameters(), lr=args.lr)

    logger.info("Starting training loop...")

    best_val_loss = float('inf')
    os.makedirs("models", exist_ok=True)

    for epoch in range(args.epochs):
        model.train()
        
        epoch_loss_total = 0.0
        epoch_loss_forecast = 0.0
        epoch_loss_impute = 0.0
        
        for batch in train_loader:
            batch = {k: v.to(device) if torch.is_tensor(v) else v for k, v in batch.items()}
            
            optimizer.zero_grad()
            loss, loss_impute, loss_forecast, _, _, _, _ = model(batch)
            loss.backward()
            
            # CRITICAL SAFEGUARD: Gradient Clipping (from ARCHITECTURE.md)
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            
            optimizer.step()
            
            epoch_loss_total += loss.item()
            epoch_loss_impute += loss_impute.item()
            epoch_loss_forecast += loss_forecast.item()
            
        avg_train_loss = epoch_loss_total / len(train_loader)
        avg_train_impute = epoch_loss_impute / len(train_loader)
        avg_train_forecast = epoch_loss_forecast / len(train_loader)
        
        # Validation Loop
        model.eval()
        val_loss_total = 0.0
        val_metrics_accum = {
            "rmse": 0.0,
            "mae": 0.0,
            "impute_mse": 0.0
        }
        zero_true_total = 0
        zero_correct_total = 0

        with torch.no_grad():
            for batch in val_loader:
                batch = {k: v.to(device) if torch.is_tensor(v) else v for k, v in batch.items()}
                loss, _, _, imputed_features, mu, _, pi = model(batch)
                val_loss_total += loss.item()

                # Calculate batch metrics
                batch_metrics = calculate_metrics(
                    target_forecast=batch['target_forecast'],
                    mu=mu,
                    pi=pi,
                    imputed_features=imputed_features,
                    target_impute=batch['target_impute'],
                    node_mask=batch['node_mask']
                )
                for k in val_metrics_accum:
                    val_metrics_accum[k] += batch_metrics[k]
                zero_true_total += batch_metrics["zero_true_count"]
                zero_correct_total += batch_metrics["zero_correct_count"]

        avg_val_loss = val_loss_total / len(val_loader)
        val_rmse = val_metrics_accum["rmse"] / len(val_loader)
        val_mae = val_metrics_accum["mae"] / len(val_loader)
        val_zero_acc = zero_correct_total / zero_true_total if zero_true_total > 0 else 0.0
        val_impute_mse = val_metrics_accum["impute_mse"] / len(val_loader)
        
        # Offensive Assertion for Divergence
        if torch.isnan(torch.tensor(avg_val_loss)):
            raise DivergenceError("Validation loss is NaN! The Burn Test Failed.")
            
        logger.info(f"Epoch {epoch+1}/{args.epochs} - "
                    f"Train Loss: {avg_train_loss:.4f} | "
                    f"Val Loss: {avg_val_loss:.4f} "
                    f"(RMSE: {val_rmse:.2f}, MAE: {val_mae:.2f}, "
                    f"ZeroAcc: {val_zero_acc:.4f} [{zero_correct_total}/{zero_true_total}], "
                    f"ImputeMSE: {val_impute_mse:.4f})")
                    
        # Checkpointing
        if avg_val_loss < best_val_loss:
            best_val_loss = avg_val_loss
            checkpoint_path = "models/best_pipeline.pt"
            torch.save(model.state_dict(), checkpoint_path)
            logger.info(f"New best model saved to {checkpoint_path} with val_loss: {best_val_loss:.4f}")

        # W&B Logging
        if init_wandb or (wandb.run is not None):
            wandb.log({
                "train_loss_total": avg_train_loss,
                "train_loss_impute": avg_train_impute,
                "train_loss_forecast": avg_train_forecast,
                "val_loss_total": avg_val_loss,
                "val_rmse": val_rmse,
                "val_mae": val_mae,
                "val_zero_acc": val_zero_acc,
                "val_zero_true_count": zero_true_total,
                "val_zero_correct_count": zero_correct_total,
                "val_impute_mse": val_impute_mse,
                "epoch": epoch + 1
            })

    logger.info("Training complete.")
    if init_wandb:
        wandb.finish()
        
    return avg_val_loss

def main():
    logger = setup_logger("train_pipeline")
    args = parse_args()
    run_training(args, init_wandb=True)

if __name__ == "__main__":
    main()

def make_objective(cli_args: argparse.Namespace):
    """
    Factory that returns an Optuna objective bound to the requested data mode.
    Separating the factory from __main__ lets us inject --use_mock_data at the
    study level without relying on a global variable.
    """
    def objective(trial):
        """
        Optuna objective function for hyperparameter tuning.
        Dynamically generates suggestions based on configs/sweep.yaml.
        """
        # Define hyperparameter search space dynamically
        params = {}
        for param_name, param_config in SWEEP_CONFIG.get("parameters", {}).items():
            dist = param_config.get("distribution")
            if dist == "log_uniform_values":
                params[param_name] = trial.suggest_float(
                    param_name,
                    param_config["min"],
                    param_config["max"],
                    log=True
                )
            elif dist == "uniform":
                params[param_name] = trial.suggest_float(
                    param_name,
                    param_config["min"],
                    param_config["max"]
                )
            else:
                raise ValueError(f"Unsupported distribution: {dist} for parameter {param_name}")

        # Map to configuration object for the training runner
        args = argparse.Namespace(
            epochs=cli_args.epochs,
            batch_size=cli_args.batch_size,
            lr=params.get("lr", 1e-3),
            w_forecast=params.get("w_forecast", 1.0),
            w_impute=params.get("w_impute", 1.0),
            use_mock_data=cli_args.use_mock_data,
            start_date=cli_args.start_date,
            end_date=cli_args.end_date,
            seq_len=cli_args.seq_len,
            veh_class=cli_args.veh_class,
            dir=cli_args.dir
        )

        # Execute training loop.
        # init_wandb=False prevents train.py from spawning a separate W&B run,
        # as the WeightsAndBiasesCallback manages the run at the study level.
        val_loss = run_training(args, init_wandb=False)

        return val_loss

    return objective

import torch

from metrics import calculate_metrics


def _make_base_tensors(batch_size: int = 2, num_nodes: int = 4, seq_len: int = 3, dim: int = 2):
    """Helper: creates zero-filled tensors matching the expected shapes."""
    target_forecast = torch.zeros(batch_size, num_nodes)
    mu = torch.zeros(batch_size, num_nodes)
    pi = torch.zeros(batch_size, num_nodes)
    imputed_features = torch.zeros(batch_size, num_nodes, seq_len, dim)
    target_impute = torch.zeros(batch_size, num_nodes, seq_len, dim)
    node_mask = torch.zeros(batch_size, num_nodes, seq_len, dim, dtype=torch.bool)
    return target_forecast, mu, pi, imputed_features, target_impute, node_mask


class TestZeroCounts:
    def test_all_zeros_in_target__all_pi_high(self):
        """All targets are 0 and pi > 0.5 everywhere → full counts."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        # All targets are 0 (already), pi set above threshold
        pi = torch.full_like(pi, 0.9)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        expected_true = target_forecast.numel()  # 2 * 4 = 8
        assert metrics["zero_true_count"] == expected_true
        assert metrics["zero_correct_count"] == expected_true

    def test_all_zeros_in_target__all_pi_low(self):
        """All targets are 0 but pi ≤ 0.5 everywhere → zero correct count."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        pi = torch.full_like(pi, 0.3)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        assert metrics["zero_true_count"] == target_forecast.numel()
        assert metrics["zero_correct_count"] == 0

    def test_no_zeros_in_target__returns_zero_counts(self):
        """No target zeros → both counts must be 0 (no fallback 1.0 bias)."""
        target_forecast, mu, pi, imputed, target_imp, mask = _make_base_tensors()
        target_forecast = torch.ones_like(target_forecast) * 5  # all non-zero
        pi = torch.full_like(pi, 0.9)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        assert metrics["zero_true_count"] == 0
        assert metrics["zero_correct_count"] == 0

    def test_mixed_targets__counts_are_exact(self):
        """Only some positions are zero; verify exact integer counts."""
        # Shape [1, 4]: target = [0, 5, 0, 10], pi = [0.9, 0.9, 0.3, 0.9]
        target_forecast = torch.tensor([[0.0, 5.0, 0.0, 10.0]])
        mu = torch.zeros(1, 4)
        pi = torch.tensor([[0.9, 0.9, 0.3, 0.9]])
        imputed = torch.zeros(1, 4, 3, 2)
        target_imp = torch.zeros(1, 4, 3, 2)
        mask = torch.zeros(1, 4, 3, 2, dtype=torch.bool)

        metrics = calculate_metrics(target_forecast, mu, pi, imputed, target_imp, mask)

        # Zeros at positions 0 and 2; pi[0]=0.9>0.5 ✓, pi[2]=0.3≤0.5 ✗
        assert metrics["zero_true_count"] == 2
        assert metrics["zero_correct_count"] == 1

import torch
import pytest
from pipeline import ResilientIoTPipeline
from torch.utils.data import DataLoader

def test_resilient_iot_pipeline():
    torch.manual_seed(42)

    batch_size = 4
    num_nodes = 50
    static_feat_dim = 10
    time_series_dim = 3
    seq_len = 12

    class MockPipelineDataset(torch.utils.data.Dataset):
        def __init__(self, size):
            self.size = size
        def __len__(self):
            return self.size
        def __getitem__(self, idx):
            dyn = torch.randn(num_nodes, seq_len, time_series_dim)
            mask = torch.rand_like(dyn) < 0.15
            dyn_masked = dyn.clone()
            dyn_masked[mask] = float('nan')
            return {
                'static_features': torch.randn(num_nodes, static_feat_dim),
                'dynamic_features': dyn_masked,
                'target_impute': dyn.clone(),
                'target_forecast': torch.randint(0, 50, (num_nodes,)).float(),
                'node_mask': mask
            }
            
    dataset = MockPipelineDataset(size=8)
    
    def custom_collate(batch_list):
        return {
            'static_features': batch_list[0]['static_features'],
            'dynamic_features': torch.stack([b['dynamic_features'] for b in batch_list]),
            'target_impute': torch.stack([b['target_impute'] for b in batch_list]),
            'target_forecast': torch.stack([b['target_forecast'] for b in batch_list]),
            'node_mask': torch.stack([b['node_mask'] for b in batch_list])
        }

    dataloader = DataLoader(dataset, batch_size=batch_size, collate_fn=custom_collate)

    model = ResilientIoTPipeline(
        num_nodes=num_nodes,
        static_feat_dim=static_feat_dim,
        time_series_dim=time_series_dim,
        seq_len=seq_len
    )
    
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

    for batch in dataloader:
        optimizer.zero_grad()
        loss, _, _, _, _, _, _ = model(batch)
        assert not torch.isnan(loss).any()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()
