description: Architect System Design
---

**Trigger:** When asked to design a new feature or analyze a bug report.

**Steps:**

1.  **Analyze Context:** Review the provided problem description, bug report, or feature request.
2.  **Consult North Stars:** Review the relevant `NSTAR_*.md` documents to ensure alignment with project principles (e.g., Offensive Programming, Decoupled Systems).
3.  **Perform Desk Check (if applicable):** If the design involves mathematical operations or tensor manipulations, execute the `desk_check` skill to validate the logic.
4.  **Draft Plan:** Create a detailed, step-by-step implementation plan and save it to `plan.md`.
5.  **Await Approval:** Present the summary of the plan to the user and ask for explicit approval before any coding begins.
