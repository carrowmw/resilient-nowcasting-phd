---
description: Codebase Investigation
---

**Trigger:** When asked to find specific code, trace an error, or summarize a module.

**Steps:**

1.  **Search:** Use filesystem tools to search for relevant keywords, file names, or error messages across the codebase (including `src/`, `tests/`, and `logs/`).
2.  **Analyze:** Read the relevant code snippets or log entries.
3.  **Summarize:** Create a concise summary of the findings, focusing on the logic, data flow, or cause of the error. Do NOT output raw code unless explicitly requested.
4.  **Report:** Present the summary to the user or the `@architect` persona.
