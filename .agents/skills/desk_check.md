# Skill: Mathematical Desk Check

**Context:** When writing tensor operations, loss functions, or complex data transformations, the "Architect" requires a manual proof of concept.

**Action:**
Before writing the actual code, output a step-by-step mathematical trace using dummy data.

1. Define dummy input tensors with extreme or edge-case values (e.g., zeros, ones, very large numbers).
2. Trace the exact mathematical operations step-by-step.
3. State the expected output.
4. Only proceed to write the Python code once this logical check is complete and verifies the expected behavior.
